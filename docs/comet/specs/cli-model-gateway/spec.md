# Capability：CLI 服务端模型网关

状态：Shape 待审阅（2026-10-19），未表示已实施。结果、边界和待确认选择见 [brief](brief.md)，协议与分批见[设计](../../../design/cli-model-gateway.md)。以下按 U1–U4 建议默认值编写；确认改变产品结果时同步更新合同。

## 合同与验收

1. 新安装的 CLI 默认选择服务端模型；已配对、获准使用且完成首次告知后，无需填写本地模型地址或密钥即可调用网页 AI 助手的有效模型配置。
2. 只有模型调用经服务端；文件读写、命令、PTY 和其他本机工具仍在本机执行，保留原有工具授权、取消与副作用保护。
3. CLI 可明确选择本地直连，沿用本机地址、模型和钥匙串密钥；此模式的模型调用不进入服务端用量统计，界面明确显示当前模式和统计范围。
4. 未配对或设备没有模型使用权限时，网关不外发并给出配对或开启权限的提示；本地模型及本机工具可独立使用，需要服务端的功能仍遵守原权限。
5. CLI 获得有效模型名称、上下文窗口、单次输出上限和共享工具上限，不能获得服务端密钥。网关拒绝客户端指定上游地址、凭据或非配置模型，不能用作开放代理。
6. 网关对 CLI 保持 Chat Completions 兼容接口，服务端适配配置的 Chat Completions／Responses 上游；不要求改变 agentcore 的模型协议。
7. 工具定义、调用标识、参数和结果在转换后保持关联及顺序；流式文字和可展示的推理增量可被现有 CLI 消费。网关不执行工具、不把推理正文加入最终回答或持久记录。
8. 成功流包含明确完成信号；截断、错误或缺少完成信号不能显示为完整成功，未完成的工具请求不得执行。usage 缺失不妨碍有效回答完成，但不得伪造用量。
9. 一个客户端请求在服务端只受理一次；重复提交、状态读取、取消或服务重启恢复不会再次调用模型。兼容回退仅在确定上游拒绝该请求且未开始输出时发生，每次真实外发分别计数。
10. 用户停止、下游断线或超时后，服务端停止后续输出和尝试并取消上游请求；CLI 保留部分展示并说明未完成。未知结果不自动重发，也不自动重做已执行的本机工具。
11. 服务端不可用、繁忙或协议不匹配时，CLI 显示可执行的重试、升级或手动直连提示；不静默切换模式、模型、地址或密钥，不在后台排队后意外外发。
12. 新配对可明确授权模型使用；旧设备不会因升级自动获得权限。用户可在设备管理中开启或关闭模型权限，现有其他权限及设备归属不因此改变。
13. 撤销设备或关闭模型权限后，新调用立即被拒绝，进行中的调用不再向 CLI 发送后续内容，并取消上游。已发生消耗保留；不承诺撤回上游已接收的数据或已送达本机的字节。
14. CLI 与网页共享总并发限制；每台设备最多占用一个网关名额，所有 CLI 合计不能占满网页名额。繁忙时立即拒绝且不外发；总并发数为 1 时提示至少设为 2 才可使用网关。
15. 一次用户轮次在现有台账中对应一项 CLI 用量任务，同轮的模型循环、上下文整理、进展说明和重试归入该任务；一次真实上游 HTTP 尝试对应一条 call。来源与设备由服务端认证确定，不能由请求正文冒充。
16. 同一本机会话的各轮可归集查看；恢复会话保持原关联，“继续”仍归原轮次，新用户输入产生新轮次。不同设备、隐私代次或学习区不能通过复用标识合并任务，不上传会话标题、目录路径或正文。
17. 用量页可按来源和设备筛选，展示任务及调用明细，并可限定本机会话；网页既有日／周／月、模型和学习区筛选与汇总口径保持一致。无学习区的 CLI 调用进入有权查看的全局统计。
18. 缺失输入、输出或推理 Token 时显示未知，汇总显示已知小计和未知调用数；推理 Token 属于输出明细，不重复相加。失败、停止和兼容回退已外发的消耗不会被抹去。
19. 服务端只在转发所需内存中处理 CLI 正文，不写数据库、队列、对象存储、临时文件或日志；台账、去重及运行状态只保存必要计数、状态和归属。HTTP 日志、错误、trace 和反向代理不得记录正文或认证秘密。
20. 首次启用及切换到另一服务端时，CLI 明确告知问题、相关对话和工具返回的本地内容将经服务端发给配置的模型服务；用户确认前不外发。日志脱敏和“不保存正文”承诺不被描述为上游供应商也不保存。
21. 用量和网关元数据服从既有身份、学习区和隐私清除规则；清除后旧请求、缓存、迟到回执不能复活原代次记录或继续转发。状态查询及会话聚合不泄露其他设备的私有请求状态。
22. 两种模式都不按累计模型请求次数或累计 Token 停止、暂停或拒绝；CLI 移除旧预算输入、余额和“增加预算继续”操作。不能通过将旧预算设为极大值假装取消。
23. 每轮工具调用上限与网页使用同一设置，默认不限；在线读取当前值，离线使用同一服务端绑定的最后同步值，无缓存时不限并说明。旧的本地最大轮数不再成为另一道隐藏限制。
24. 设置正整数上限时，实际执行的每个工具请求计一次；达到上限后收回工具，最后说明进展并等待“继续”，继续后重新计数。普通交互或授权等待不重置次数；说明失败仍停住，不借重试绕过上限。
25. 单次输出和上下文窗口仍是硬限制；CLI 使用服务端下发值规划上下文，服务端也校验请求，不外发已知超窗请求。本地模式保留本机对应限制；文件、存储、权限和 I/O 限制不随预算取消而删除。
26. 已有本地配置升级后可继续读取，原密钥和配置不删除、不上传；首次迁移提供明确选择。在用户选择前保留原本地模式，切换或恢复旧会话不自动重新执行工具。
27. 模型配置在一次请求内固定；下一次调用遇到配置改变时先刷新、重算上下文，模型服务或模型改变须先向用户说明并确认。任何未获准的新外发都不计为已调用。
28. 旧 CLI 连新服务端仍按原模式运行；新 CLI 连旧服务端或不兼容网关时明确提示升级或手动直连。旧客户端不能绕过新鉴权，升级不会自动扩权、重放历史调用或改写旧客户端不能读取的原配置。
29. 正式部署经 nginx 可完成配置读取、模型流、状态和取消请求；代理不能缓冲流或把正文落临时文件，未知路径与管理入口不因网关上线而额外开放。
