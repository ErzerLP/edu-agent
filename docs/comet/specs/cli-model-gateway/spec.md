# Capability：CLI 服务端模型网关

状态：Shape 已确认（2026-10-20），Ready，可进入 Build，尚未实施。结果和边界见 [brief](brief.md)，协议与分批见[设计](../../../design/cli-model-gateway.md)。以下为 U1–U4 决定后的完整合同。

## 合同与验收

1. CLI 只通过已配对服务端调用模型；移除本地 provider 预设、模型地址、任意模型名、模型密钥及直连路径。首次运行引导配对、选择服务端模型并确认隐私告知，无需填写上游参数。
2. 文件读写、命令、PTY 和其他本机工具仍在本机执行，保留原有授权、取消与副作用保护；不新增脱离模型的工具运行模式。已有不调用模型的独立命令保持原行为。
3. 未配对、凭据失效或缺少模型权限时不外发，提示配对；服务端不可用时停止模型调用并提示重试，不能通过缓存或其他路径继续调用模型。
4. 可选列表只包含网页已配置、已启用的 teaching／mentor 连接，不包含 search；CLI 获得 target、名称、显示信息、有效上下文窗口和输出上限及必要控制元数据，不获得 endpoint 或密钥。服务端拒绝任意模型、地址、凭据和代理参数。
5. CLI 能列出、选择并按服务端与设备记住连接；请求以 target 指定连接，不以上游模型名寻址。多个候选时由用户选择，唯一候选可在首次告知确认后选定；已有选择失效时停止并提示重新选择，不自动替换。
6. 单次请求冻结所选连接与上限；下一次请求遇到变化先刷新。仅上限变化时重算上下文，模型或发送目的地变化时先说明并确认；禁用或不可用的连接不再接受新调用。用量按实际使用的连接模型记账。
7. 网关对 CLI 提供 Chat Completions 接口，服务端支持 Chat Completions／Responses 上游；不改变 `packages/agentcore` 模型协议。前台、上下文整理、自动标题和连接测试全部使用同一网关及所选连接。
8. 工具定义、调用标识、参数和结果经转换后保持关联及顺序；现有 CLI 可消费流式文字及可展示的推理增量。网关不执行工具，不将推理正文加入最终回答或持久记录。
9. 成功流有明确完成信号；截断、错误或缺少完成信号不能显示为完整成功，未完成的工具请求不得执行。usage 缺失不妨碍有效回答完成，但不得伪造用量。
10. 一个客户端请求只受理一次；重复提交、状态读取、取消或服务重启恢复均不会再次调用模型。上游协议选项回退只允许在确定拒绝且未开始输出时发生，每次真实外发分别计数。
11. 用户停止、下游断线或超时后停止后续输出和尝试，并取消上游请求；CLI 保留部分展示并说明未完成或结果未知。中断后不自动重发，不自动重做已执行的本机工具。
12. 服务端繁忙、不可用或上游不支持请求时，CLI 给出重试或检查网页设置的明确提示；不静默换用另一连接，不在后台排队后意外外发。
13. 新 CLI 配对 profile 直接包含模型使用 scope，浏览器会话不能替代设备模型鉴权。撤销设备后立即拒绝新调用，停止进行中调用的后续输出并取消上游；已发生消耗保留，不承诺撤回已到达模型服务或本机的内容。
14. 网页与 CLI 共享总并发，默认 10、范围 1–16；每设备最多 1 个网关请求，CLI 合计最多总并发减一，默认 9 个。繁忙立即拒绝且不外发；总并发为 1 时提示至少设为 2。
15. 一次用户轮次对应一项 CLI 用量任务，同轮模型循环、上下文整理、自动标题、进展说明和用户重试归入该任务；一次真实上游 HTTP 尝试对应一条 call。来源和设备由认证确定，不能由正文冒充；连接测试单独归集。
16. 同一本机会话各轮可归集；恢复会话保持关联，“继续”沿用原轮次，新用户输入产生新轮次。不同设备、隐私代次或学习区不能复用标识合并任务；会话关联元数据不包含标题、目录路径或正文。
17. 用量页可按来源、设备、实际模型和本机会话筛选，展示任务及调用明细；既有日／周／月、学习区筛选和汇总口径保持一致。无学习区的调用进入有权查看的全局统计。
18. 缺失输入、输出或推理 Token 时显示未知，汇总显示已知小计和未知调用数；推理 Token 属于输出明细，不重复相加。失败、停止和协议选项回退已外发的消耗不会被抹去。
19. 服务端仅在转发所需内存中处理正文，不写数据库、队列、对象存储、临时文件或日志；台账、去重和运行状态只保存必要计数、状态和归属。HTTP 日志、错误、trace 和反向代理不得记录正文或认证秘密。
20. 首次启用及切换另一服务端时，明确告知问题、相关对话和工具返回的本地内容会经服务端发送给所选模型服务；用户确认前不外发。“服务端不保存正文”不代表上游供应商也不保存。
21. 用量和网关元数据服从既有身份、学习区与隐私清除规则；清除后旧请求、缓存和迟到回执不能复活原代次记录或继续转发。状态查询及会话聚合不泄露其他设备的私有状态。
22. 不按累计模型请求次数或累计 Token 停止、暂停或拒绝；移除预算输入、余额、增额操作及接口残留，不能用极大数值代替取消预算。
23. 每轮工具调用上限与网页使用同一设置，默认不限；每轮开始或明确“继续”时读取当前值，本轮内固定。无法读取时停止并提示重试，不保存用于离线运行的工具上限；CLI 本地最大模型轮数不再形成另一道限制。
24. 设置正整数上限时，每个实际执行的工具请求计一次；达到上限后收回工具，说明进展并等待“继续”，继续后重新计数。普通交互或授权等待不重置，说明失败仍停住；多工具回复不能越过剩余次数，已完成工具不重跑。
25. 单次输出和上下文窗口仍为硬限制；CLI 用服务端下发值规划前台及内部请求，服务端也校验，不外发已知超窗请求。文件、存储、权限和 I/O 边界不随预算取消而删除。
26. 会话恢复、连接选择与配置刷新本身不调用模型、不执行工具；恢复后只有用户发起或继续的一轮才能发送所需上下文。服务端、设备或目的地变化重新核对授权和归属，本机会话正文仍留本机。
27. 正式部署经 nginx 可完成配置读取、模型流、状态与取消；代理不缓冲流、不把正文落临时文件、不自动重发 POST，未知路径和管理入口不额外开放。
