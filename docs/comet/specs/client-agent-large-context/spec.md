# Capability: CLI Agent 大窗口与长输出

用户结果：新配置默认使用 272000-token 总窗口和 128000-token 最大输出；长回答可安全接收、显示、保存、恢复并继续对话。此合同覆盖旧 learning-agent 中默认窗口/固定输出预留/最近两轮硬保留的冲突部分，其他行为保持。

## 合同

- context_window 默认 272000；max_tokens 默认且本阶段最高 128000，可显式调低。已有显式窗口不改写，旧配置缺少新字段按新默认加载。CLI 设置、查看、启动与恢复一致。
- 每次请求输入估算、有效输出额度和至少 5% 安全余量之和不超过窗口。短输入默认窗口下的主请求实际发送 max_tokens=128000；小窗口或长历史可减少当次额度，不修改配置。
- 内部标题、Observer、Reflector 请求维持原有小额度。provider 不支持配置时明确报告，不伪装协商成功。
- 普通与流式主回答都可接受超过旧 64 KiB 的文本，最大正文初始对齐流式 1 MiB 防护；正文容量与 token 数不等价，不承诺任意编码都能填满 128000 tokens。
- 细粒度长 SSE 不再受旧 4096 事件/8192 行误拒；仍有有限总量、单事件/增量、空闲超时、协议验证和取消约束。不得取消资源防护或保存隐藏推理。
- 合法长正文能显示并在 Session 配额内完整保存/恢复；长度、序列化膨胀、行数校验不能彼此冲突。总配额不足要显式报告，不静默截断后声称保存完整。
- 当前不可压缩轮次必须保留，tool call/result 不能拆散；旧完整轮次优先保留，但不足时可降为带来源和显式状态的有界投影，不得遗失副作用或授权事实。context_compaction=off 仍不静默裁剪。
- 新旧会话可恢复。只有实际改变持久化格式/合同的地方升级版本，旧 DTO 保持严格，未知未来版本 fail closed。恢复不重放文件操作。

## 验收

1. 新配置和 CLI show 显示 272000/128000；合法下调成功，负数、零显式参数和超上限拒绝。
2. 旧配置加载保留已有窗口与其他用户设置；未显式操作不写本机配置。
3. 默认短请求普通/流式均发送 128000，估算+输出+余量不越界。
4. 已有最小窗口工作区的有界请求仍可用。
5. 超过 64 KiB 的普通和流式回答被接受，超过新正文防护拒绝。
6. 超过 4096 个细粒度事件的合法输出成功，空流/异常事件洪泛仍有界。
7. Esc/取消停止当前请求且不破坏已完成副作用事实。
8. 多行长答复保存和恢复一致；配额失败有明确结果。
9. 长答复后再次提问可在预算内继续；降级可见、来源可追溯。
10. tool call/result 投影完整，off 模式不静默裁剪，标题和压缩请求仍是小预算。
