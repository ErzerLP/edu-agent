# Capability: 用户主动归档清理

结果：Go CLI Agent能对用户明确选择并确认的归档范围执行永久清理，保留完整逐项事实，诚实报告删除、部分失败、未处理和未知，而不是仅移动归档位置或隐藏目录。

状态：生产闭环及Linux批次门禁已完成；尚非Runtime或整个Issue验收，macOS原生与最终独立复核仍待。实现与证据进入[交付计划](../../../design/client-local-tools-delivery.md)。

## 合同与验收

1. 新增purge_archive，严格要求归档内确切path及当前stat的expected_version。范围可为归档容器、文件或子目录；不得为workspace根、归档根本身、归档外路径、通配范围或含糊的“全部”。定位复用既有分页工具，不猜测历史布局。
2. 每次清理在不可逆执行前展示冻结范围、完整计划定位和永久删除风险，要求一次明确批准；当前Session YOLO不代替此次清理确认。查看完整计划不调用模型、不新增末页或逐文件审批。拒绝或执行前取消不删除任何入口。
3. 授权前完整枚举有界计划，包含所选范围内每个待删除入口。无法完整枚举、保留计划或确认资源预算时不开始删除。准备不创建目录、移动用户数据或删除临时归档。
4. 文件和目录按冻结清单执行，目录在已选后代之后移除。不动态扩展到授权后新增内容，不自动删除冲突项，不恢复或回滚已删除项。超过2000项的目录可在明确预算内完整清理。
5. 仅清理真实归属于当前规范归档根的入口；路径组件、归档根与父身份在执行时重新核查。禁止路径逃逸、归档别名、替换或移出的父目录，以及跨挂载点遍历。平台不能证明所需安全边界时明确拒绝，不回退到Shell、RemoveAll或宽松路径删除。
6. 普通文件（含大二进制）只删除目录入口，不读取正文。目录内链接只删除链接本身、不跟随目标；外部链接目标和未选范围不变。设备、管道等特殊入口使计划预检拒绝，不扩大特殊文件支持。
7. 冻结入口版本不是正文hash、子树原子快照或跨进程CAS。执行前完整核对计划，逐项再核对身份/版本和归属；自身删除造成的目录元数据变化不被误作新授权，非空目录不递归兜底删除。
8. 每项先确认意图，再尝试不可逆删除，随后记录实际结算。失败、变化、取消、结算保存失败或未知立即停止余项；已完成项保留，后续项明确not_started。等待/显示失败不抹去已知删除事实。
9. 结果分别报告完整计划项数、尝试/完成/未变化/未知/未处理、清理范围及日志访问位置。整体完成仅在全部项和必要同步得到确认后声明；不能确认的结果不能冒称未删除或已完成。
10. 报告已删除普通文件的逻辑字节及其统计范围，不将其当作实际释放空间。硬链接、稀疏文件、打开的文件和文件系统快照可能使实际释放量不同；无法测定实际释放量时明确unknown，不伪造精确值。
11. 完整清单与追加逐项回执独立于聊天摘要，可用artifact与F6分页/检索；plan不证明执行，pending无actual为unknown。实际可读字节与确认保存字节分开，不提升孤儿尾部，也不因截断摘要遗失未返回结果。
12. 持久Session使用同Session认证加密、配额、provider门禁、在用锁及delete/clear边界。完整计划/日志正文和原始参数不进入稳定checkpoint/transcript/自动标题。--no-save只在有界内存保留自动历史，不妨碍用户明确批准的真实删除。
13. 清理根WAL和独立调用身份遵守不重放合同；消费WAL或重启后旧ID不能再次清理，也不能换路径重放，合法新ID仍可执行。恢复只读展示事实，不恢复批准、剩余执行器或自动继续清理。
14. 删除使相关旧文件/目录观察失效，保留历史操作事实；模型、确认、活动详情及恢复提示明确永久清理，不得沿用复制/恢复文案或称可撤销。
15. 使用明确有界、可配置的批量计划/入口/日志保留预算，达到预算不自动淘汰历史或静默缩小范围。大文件不因copy的文件字节上限阻断清理；不同预算及作用范围必须清楚披露。
16. 原archive/restore_archive及普通写工具权限不扩大；无自动过期、后台清理、按磁盘压力删除、归档外通用delete或安全擦除承诺。保留未选归档与归档根，不顺带清理父容器。
17. 验收覆盖真实文件/二进制/空目录/嵌套目录/内部链接、2501项计划、硬链接空间说明、冲突/取消/未知/部分完成、加密与no-save、严格旧版本迁移、模型至TUI、WAL恢复不重放及合法新ID。Linux/macOS为支持范围，交叉构建不代替macOS原生证据。
