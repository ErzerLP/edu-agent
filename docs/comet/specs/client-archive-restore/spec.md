# Capability: 归档定位与恢复

结果：Go CLI Agent能分页定位已有归档，选择确切归档入口及明确目标，在不覆盖现有文件的前提下安全恢复，并向模型与客户端报告实际位置和真实结果。

状态：生产闭环及Linux批次门禁完成；尚非macOS原生、Runtime或整个Issue验收。实现与证据进入[交付计划](../../../design/client-local-tools-delivery.md)。

## 合同与验收

1. 复用list/find/read/stat查看`.edu-agent-archive`及内容，分页不受旧单目录2000项窗口截断。目录不存在、无法读取、扫描未完、结果未返回或游标失效分别报告，不以空列表掩盖。
2. 新增restore_archive入口，必须指定确切source、destination和当前stat入口版本expected_version；选择的是归档树内文件或目录，不是归档根/容器本身。旧归档无可信原路径记录时不从布局猜测原位置，本版始终要求显式目标。
3. 恢复目标是同一workspace内的非归档相对路径，目标入口必须不存在、父目录已经安全存在。默认不覆盖、不合并、不自动创建父目录、不归档或删除冲突项。
4. 使用同文件系统不覆盖移动恢复普通文件（含大二进制）或整个目录，不经模型搬运正文，不以复制后删除兜底；跨文件系统或不支持安全移动明确拒绝。
5. 源和目标各组件不跟随链接，归档根和归档源父目录的真实身份及归属须核实；不允许借路径别名、目录替换/移出或大小写变体扩大归档权限。不得因此放宽普通write/edit/copy/move等对归档树的保护。
6. 归档目录内部链接随整体目录保留、不遍历；不将其目标复制或删除。入口版本不是内容hash、子树快照或跨进程CAS；恢复不声称修复归档内相对链接语义。
7. 默认沿用文件修改确认和当前Session YOLO。授权展示冻结的归档源、恢复目标、类型、当前入口版本和冲突/未知风险；拒绝或执行前取消不改变两端。恢复不需要新增逐页或额外审批。
8. 执行前复核冻结源版本、归档归属与两端父身份，原子不覆盖发布并同步必要目录。并发创建目标不能被覆盖；源变化或父目录变化不得偷偷改用新入口。
9. 准确区分completed、unchanged和unknown。晚取消、同步/关闭失败或无法确认发布时保留真实位置及未知提示，不自动回滚、清理剩余归档容器或重试。
10. 持久Session执行前记录不可执行WAL、之后记录实际结算；成功与未知均保留完整归档源/目标和版本含义，不伪造目标内容hash或把旧版本当新版本。仅有WAL时恢复报告未知，不恢复批准/候选或执行操作。
11. 已记录恢复调用身份不得因消费WAL或重启而再次执行；同ID不能更换目标重放，合法新ID不被误当保存失败阻断。历史回执不证明文件当前仍位于恢复目标，后续操作须重新stat/read。
12. 恢复失效归档源、恢复目标及相关父目录/子树的旧观察，但不删除历史操作事实。模型投影、恢复状态及TUI须保留完整双端定位；不截造路径或错误展示为“复制、源未修改”。
13. 加密WAL、回执与调用身份遵守原Session密钥、provider发送门禁、在用锁、delete/clear和严格版本迁移。--no-save不保存自动历史，实际恢复仍是显式文件副作用。
14. 验收覆盖真实归档后恢复、旧无manifest归档、分页定位、二进制/目录/内部链接、冲突、版本/父目录变化、拒绝/取消/未知、WAL与结算失败、模型至TUI、重启防重放及no-save。Linux/macOS为支持范围；交叉构建不替代macOS原生证据。

非目标：默认原路径推断、目录合并/覆盖、跨文件系统复制删除、自动重试、恢复会话执行器、永久清理或自动过期。主动归档清理由C10单独交付。
