# Capability: 安全文件复制 copy

结果：Agent能不经过模型正文复制普通文件，包括二进制，保留源且不覆盖目标。

## 合同与验收

1. 接口source/destination/expected_version必需；源版本来自stat；未知字段拒绝，不提供overwrite/force。
2. 仅普通文件，源上限32MiB独立于文本工具1MiB；不复制目录/链接/特殊入口。
3. 源目标均是安全工作区相对路径且均不能位于归档树；目标必须不存在，父目录必须已存在。
4. Prepare无文件副作用，冻结源入口元数据版本、目标、父身份和授权呈现；不得让模型选择客户端临时路径。
5. 默认确认，YOLO只略过确认；提交前重新核验源版本和双端打开句柄、归档边界；拒绝/取消不发布目标。
6. 流式读取已核验源、写目标父目录下客户端专有临时文件，不经模型传正文；复制前后检查源可观察变化，不承诺跨进程完整快照。
7. 最终不覆盖发布；目标竞争创建不得覆盖；保留源字节。不借copy自动恢复归档。
8. 明确普通文件权限策略，不传播setuid/setgid等特殊权限，不承诺ACL/扩展属性/硬链接关系完整保留。
9. 使用C6副作用记录，在发布前持久化；completed/unchanged/unknown与真实磁盘一致，恢复不重放、unknown不自动重试；临时文件清理仅限客户端拥有项。
10. 目标与父列表、相关发现/搜索证据失效，源不被伪报修改；覆盖二进制一致性、大于1MiB文件、32MiB边界、源变化、目标冲突、取消、归档保护、WAL失败和恢复。

延期：目录递归复制、覆盖、跨文件事务、完整元数据复制。不得使用Shell或安装外部工具。
