# Capability: 路径发现 find

结果：Agent 能按文件名/工作区路径模式定位文件和目录，不需全文扫描。

## 合同与验收

1. 接口 path 默认`.`、pattern必需、type为file/directory/any默认any、limit默认200；拒绝未知字段与无效类型/模式/预算。
2. 输出统一工作区相对路径，包含入口类型，排序确定；不泄露绝对根。
3. 无斜杠pattern匹配basename；有斜杠匹配工作区相对完整路径；`*`与`?`不跨目录，单独路径组件`**`跨零或多层，字符类需明确验证。
4. 在安全根内递归，不读取文件正文、不跟随链接；特殊入口不作为可操作普通文件。
5. 普通范围跳过归档树；显式归档范围可只读发现。
6. 默认保留隐藏文件，不自动采用.gitignore；之后C5显式respect_gitignore加入时缺省行为不变。
7. 默认最多200条结果、10000遍历入口、64层深度、6KiB输出，并受工具超时/取消约束；limit可降低，不可突破客户端上限。
8. 结果包含complete、truncation_reason以及扫描/跳过统计；未完成不能报告穷尽性，没有虚假的续页游标。
9. 调用无副作用、无写授权，结果是工作区快照；mkdir/copy/move/archive影响相关范围后旧发现证据能失效。
10. 覆盖根/子目录、空结果、嵌套glob、隐藏文件、归档、链接、取消、边界和生产注册/投影/恢复。

延期：后台索引、无限扫描、外部fd下载/执行、长期游标、.gitignore（由C5实现）。
