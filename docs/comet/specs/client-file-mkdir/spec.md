# Capability: 安全目录创建 mkdir

结果：Agent能通过冻结授权创建空目录和显式多级目录，并正确记录/恢复目录副作用。

## 合同与验收

1. 接口path必需、parents默认false，未知字段拒绝；不接受工作区根、归档树、不安全/外部路径。
2. 已存在普通目录返回unchanged且不伪报新建；已有文件/链接/特殊对象拒绝。
3. parents=false要求父目录已存在；parents=true只创建计划内缺失目录，数量、深度、输出受现有有界路径/预览约束。
4. Prepare无磁盘副作用；冻结路径、父入口身份和待创建目录，授权完整呈现重要路径，不通过截断路径获得同意。
5. 默认逐次确认、YOLO可跳过确认但不跳过路径/版本/归档安全检查；拒绝和prepare取消不创建目录。
6. Commit重新检查打开父句柄仍在工作区且不在归档，父路径替换/迁移、别名等攻击fail closed；不依赖字符串检查。
7. 多级创建中途失败记录已知创建项，不永久删除目录回滚；completed只有全部目标完成，其他副作用按保守unknown并明确说明。
8. 引入最小统一文件副作用记录，足以表达操作、源/目标、类型、版本、受影响范围和已知附带创建项；旧write/edit/archive记录通过显式版本兼容，不放松旧DTO验证，未来版本拒绝。
9. 记录必须在首次副作用前写入；持久化失败不创建。恢复只说明完成/未知及已知路径，不自动重放，不把未知当未发生。
10. 正确失效新目录、父列表和相关find/search；历史副作用仍作为事实保留。具名覆盖拒绝、YOLO、冲突、部分创建、取消、WAL失败、保存恢复与目录保护。

延期：chmod/chown、临时事务回滚、目录删除、服务器改动。统一记录只为本批所需建最小结构，不一次实现copy/move。
