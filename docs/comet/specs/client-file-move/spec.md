# Capability: 安全文件与目录移动 move

结果：Agent能安全重命名或移动普通文件与整个目录，严格不覆盖、不永久删除、不使用跨设备复制后删除。

## 合同与验收

1. 接口source/destination/expected_version必需，版本来自stat；无overwrite/force，拒绝未知字段。
2. 支持普通文件（含二进制）、空或非空目录；源入口链接/特殊对象拒绝。目录内部链接原样随目录移动但不遍历，不声称冻结子树内容。
3. 双端限工作区，源不得为根，源/目标均不得在归档树；不得将目录移入自身后代。
4. 目标必须不存在，父目录已存在。相同规范路径可诚实unchanged；大小写单独变更/身份别名/硬链接冲突不能安全支持时明确拒绝，不能两步临时重命名兜底。
5. Prepare无副作用并冻结源版本、双端父身份与完整预览；默认确认、YOLO仅略确认。
6. Commit在打开句柄上再校验两端根内/非归档、源版本、目标不存在，采用支持平台的不覆盖rename；不把Archive入口放宽为通用move。
7. 仅同文件系统；跨设备或不支持安全原语返回明确错误，不复制后删除，不自动归档冲突目标。
8. 已持久化的副作用回执先于rename；WAL失败不移动。取消、unknown、恢复如实显示两端，不自动重放或重试。
9. 失效源与目标及目录两侧子树、两侧父列表和相关发现/搜索；历史回执保留。不会把源消失当成永久删除成功。
10. 覆盖文件/目录/内部链接、冲突、自身后代、归档、父替换/移动、跨设备拒绝、取消、WAL失败和恢复。Linux原生与Darwin/Windows编译/原生证据分别记录。

延期：跨设备移动、覆盖、归档恢复、普通目录删除、跨进程线性化事务。只复用低层安全rename原语，不复用归档目标授权。
