# Capability: 可续扫的目录与文件检索

结果：Go CLI Agent 可通过既有list/find/search分次完成超过单目录2000项的发现/检索，继续读取先前未返回的结果，且不会把扫描暂停、结果尚未读完、真实无匹配或变化失效混为一谈。

状态：生产路径和Linux批次门禁已完成；仍缺macOS原生及最终独立验收，不代表Runtime或整个Issue完成。技术状态与预算见[交付设计](../../../design/client-local-tools-delivery.md)。

## 合同与验收

1. 既有list/find/search入口、路径/glob/文字/正则/大小写筛选和search content/files/count的含义保持；新增进程内游标允许继续同一查询，不引入后台索引或下载执行外部工具。
2. 在明确资源预算内，单目录超过2000项、超过单次遍历/文件/字节或结果数量窗口均可继续；不得通过每次从头扫描相同前缀伪造续扫。
3. 游标绑定当前workspace实例、工具、完整规范化查询与真实遍历位置。参数不匹配明确拒绝，跨实例、恢复/切换、过期或资源回收后的游标明确失效；不静默重启或重放查询。
4. 区分扫描未完、查询范围存在不可扫描缺口、已找到但尚未返回结果以及完整扫描后无匹配。search计数只在范围扫描完整时称完整，不以空页或单页末尾暗示全局无结果。
5. 返回路径/匹配位置排序确定。需要先完成当前目录枚举以确定顺序时可返回无正文的扫描进度页和有效续扫位置；不伪造全目录快照或外部文件锁。
6. 续页前复核已观察的目录/目标与实际采用的忽略文件（含先前不存在状态）。发现替换、内容/元数据变化、链接或移出安全范围时明确cursor_stale，不混合旧结果与新版本。
7. 扫描及分页分别受有界资源限制，达到终止性容量或深度限制、权限/格式等故障要报告不完整原因与已保留范围。不能为了完成遍历移除路径/链接/权限检查，也不以默认工作区之外内容补齐结果。
8. 工具返回、模型当前预算投影、历史和recall缩短结果时只保留完整条目/匹配定位，续位置必须对应实际返回的条目；不得截短路径后当作新路径或跳过未返回项。正文省略与扫描完整性分别披露。
9. search同一文件的后续匹配可续读，保留真实行号/列、UTF-8安全有界预览及邻近行；files每文件只计一次，count仍按匹配行而不是出现次数累计。
10. find/search默认仍不遵守.gitignore；显式开启时沿用安全有界规则加载，忽略只是筛选而不是授权。普通范围跳过归档，显式归档只读可查；发现型操作不跟随链接。
11. 查询状态只存在有界进程内内存中，无明文侧车、持久化游标或恢复队列；--no-save不落盘，关闭workspace释放目录句柄。历史结果是历史证据，不代表游标恢复有效或磁盘当前状态。
12. 初次调用及继续调用均接受取消/超时；失去可证明遍历位置时废止查询并明确报告，不能在取消后继续无界后台扫描。
13. 客户端活动和最终摘要明确扫描/分页状态，不需追加文件写授权或让用户审批日常续扫。模型可使用返回位置继续；不把是否自动完成所有页面当成模型一定会执行的承诺。
14. query容量与保留策略集中、可注入并有客户端配置，new/resume/F2使用当前客户端设置；达到容量不无限分配，回收造成的游标过期必须可观察。
15. 验收覆盖真实大目录、单文件多页匹配、变化/忽略规则失效、拒绝路径/链接、所有search输出模式、缩短投影后无丢项、模型到客户端活动及恢复后的过期语义，支持Linux/macOS；交叉构建不替代原生运行证据。

不在本单元：扩大search单文件正文预算、无限扫描、全局/跨重启快照、数据库/全文索引、持久查询产物、复制或归档变更、Windows产品支持。C8/C9只复用安全遍历基础，不在C7顺带实现。
