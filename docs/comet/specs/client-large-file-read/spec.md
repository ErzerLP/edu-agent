# 大文件范围读取（Issue #1 C4）

状态：生产闭环与Linux批次门禁已完成；用户已批准v2轻量方案。本合同不代表Runtime、macOS原生或整个Issue #1最终验收通过。

目标：模型通过既有read入口读取超过旧1MiB边界的文本范围，并在版本和输出预算明确的前提下连续查看。实现与交付边界见[设计](../../../design/client-local-tools-delivery.md)。

1. 在声明的完整文件处理预算内，超过1MiB的UTF-8文件可读取后半部分，不要求将全文作为模型参数或输出。
2. 原有行offset/limit和行内byte_offset语义保持；恰在线尾的起点可规范化到下一行，结果起点必须对应真实正文。长行超过1MiB、文件超过一百万行时仍可定位到预算内的后续范围。
3. content_hash始终是原始完整文件字节的SHA256，包括BOM和换行；不把片段hash冒称完整版本。
4. 携带expected_hash时，文件任意位置变化必须明确拒绝旧版本；读取期间检测到变化不返回拼接成功。无expected_hash的独立读取不承诺与先前调用同版本。
5. 返回内容保持现有UTF-8、BOM展示与换行语义。UTF-8错误或二进制特征在所选范围之外也不能被短页隐藏；不放宽链接与特殊入口政策。
6. next_offset/next_byte_offset对应实际返回的内容。工作区结果、live/history/recall投影及当前轮次预算进一步缩短正文时，都不得跳过未返回部分；空前缀保留起始位置。
7. 区分文件读取完成与结果未返回完；空文件、文件尾、超出EOF范围及超长行边界不制造额外行、重复字节或永久不可前进的有效页。
8. 完整读取预算与单次参数、结果、模型上下文及写入预算独立。超预算明确失败并指向调整预算或Shell范围处理，不伪装为空文件或成功的完整读取。
9. CLI可配置读取预算；新会话、resume及同客户端F2切换使用当前客户端配置，不从目标会话静默恢复旧资源设置。默认值和当前限制在帮助/工具信息中可见。
10. 路径仍绑定工作区安全root，越界、链接父目录和被拒入口不能通过扩大文件预算获得访问权限；Shell的独立权限合同不变。
11. 取消/超时不伪装成功；读取不修改目标、不请求写授权，不新增全文历史sidecar或自动落盘暂存。现有有界读取投影与Session隐私合同保持。
12. 本批不扩大write/edit、stat(hash=true)或search的文件预算，不新增patch、检索游标、复制、归档或内容上传能力。
13. 验证覆盖真实大文本/长行/多行与fake-provider生产工具调用、投影后续读及客户端可见活动；不能只以底层函数或schema存在代替完成。

非目标：GB级固定内存或低IO承诺、持久读取游标、流式编辑引擎、服务端/数据库变更、Windows支持扩展。
