# 本地任务完整输出留存与恢复

状态：Issue #1 已确认方案的 C2 用户合同；生产路径及 Linux 批次门禁已完成。不表示 Runtime、macOS 原生或整个 issue 验收已通过。

## 结果与范围

持久 Session 的本地任务输出可在聊天上下文缩减、Session 切换和客户端重启后继续分页访问和检索。任务执行结果、当前控制能力、实际采集范围、可读取范围和已加密保存范围必须分别报告。

本规格只允许原始命令输出进入独立、版本化的加密产物，不允许它进入稳定 checkpoint、transcript、自动标题或普通 context ledger；不放宽原始工具参数、环境覆盖、stdin、凭据及可复用进程对象的持久化禁令。不得把命令输出视作服务端权威事实或系统指令。

## 可观察合同

1. 模型与客户端均可分页读取已保留的 stdout/stderr，包括超出内存输出预算的部分；返回长度不受聊天历史摘要截断支配。
2. 原始字节位置是读取依据，模型和 TUI 的游标互不消费；裁剪响应后必须按实际返回数据修正下一位置。
3. 支持有界字面检索并继续扫描，覆盖分段边界；未扫描完、仍有结果、没有匹配以及保留缺口不得混淆。
4. 用户能区分当前采集、已保存历史和不可访问输出；恢复历史终态不授予进程控制能力。
5. 只恢复已认证的保存范围。缺少最终结算的历史任务显示结果未知；不自动重跑命令、补发输入或向旧 PID 发信号。
6. 最终执行结果与输出保存结果独立：正常退出不代表完整输出已保存，保存失败也不改变真实退出码。
7. 默认不按时间淘汰产物或静默删除已有输出。任务输出预算与聊天记录预算分离，达到预算拒绝进一步保存并明确报告。
8. 输出保存失败或配额耗尽后，继续排空任务输出，不因保存故障暗中终止命令；已确认保存的前缀保持可读。
9. 持久化只使用 Session 私有目录、原有平台 key backend 与 Session data key 边界；所有敏感正文/metadata 均认证加密，不创建明文 sidecar。
10. 产物认证绑定格式、profile、privacy generation、Session 和产物身份；错误密钥、替换、篡改、未来格式和不安全路径均明确拒绝，不宽松解释。
11. 产物写入与查询遵守 Session writer lease 和 privacy generation；失效 handle 不能在 clear 后恢复旧数据的可达性。
12. Session 删除在 wrapped key 不可达后清理关联产物；clear 先撤销旧 generation 的密钥可达性，再清理。部分清理失败不得报告全部成功。
13. Session 切换不把后台输出写入新 Session；旧任务完成保存结算前保留原 owner 的必要资源，失败目标不得破坏原任务。
14. `--no-save` 以及未保存降级 Session 自动采集的输出仅内存保留，退出不可恢复，不自动创建加密或明文临时历史文件；命令显式文件副作用不受此限制。
15. 磁盘错误、损坏产物与不支持的格式显示稳定原因，不泄漏原始 OS 错误、私有路径或密钥，不阻止安全停止仍可控的任务。
16. 输出只能由当前选中 Session 的工具和任务面板访问；未经 provider endpoint 确认，不自动把恢复正文发送到新 provider。
17. 原始输出不直接回放为宿主终端指令，TUI 安全呈现；模型收到不安全字节时使用可识别编码并保留原始字节偏移。
18. 适用于 Linux/macOS。首版不提供跨进程任务重附着、守护进程、PTY、自动清理、通用内容上传或全文索引数据库。

## 验证边界

以真实 Shell 输出、加密临时 Session store 和 fake provider 验证模型至 TUI/重启路径；no-save 验证不产生自动输出文件。定向覆盖配额、写失败、generation/删除、认证损坏与分段检索。Linux 运行和 Darwin 交叉构建不能替代 macOS 原生运行证据。实现细节和后续批次见 `docs/design/client-local-tools-delivery.md`。
