# Capability: 递归目录与大文件复制

结果：Go CLI Agent通过既有copy入口，在明确资源预算内复制普通文件（含超过32MiB的二进制）或完整目录树；模型与客户端可核对冲突、实际完成项、未知项及未执行项，不因旧32项dirty日志限制而将大目录默认为完成。

状态：生产垂直路径与Linux批次门禁已完成；不代表Runtime、macOS原生或整个Issue最终验收。技术设计与批次证据见[交付计划](../../../design/client-local-tools-delivery.md)。

## 合同与验收

1. copy继续使用source/destination/expected_version，相对路径与完整stat入口版本规则保持；目录源启用递归复制，不靠Shell、系统cp或模型搬运文件正文。
2. 普通文件与二进制在当前客户端复制预算内可超过32MiB，逐块复制及计算实际目标字节hash，不按文件大小整体读入。预算独立于read/edit/write/search，不将大复制等同于无界资源。
3. 目标根必须不存在、已有父目录必须安全；默认不覆盖、不合并现有目录、不自动创建缺失的根父目录。拒绝自身/自身后代、路径别名冲突和归档树的普通写入。
4. 源与目标始终保持workspace/root/no-follow边界。目录树中的链接和特殊文件不跟随、不当作普通文件复制；预检发现不能支持的入口时明确拒绝，不先执行可知不完整的计划。
5. 授权前完整枚举并冻结有界复制清单、源入口版本、目标映射、大小与必要权限信息，预检已知冲突。源入口版本不冒充内容hash、整个子树快照或跨进程锁。
6. 沿用copy专用确认与YOLO规则；授权指向冻结的完整范围。短摘要明确文件/目录数量、字节数和部分完成风险，完整清单可独立查看；不新增逐文件确认或F6末页审批门槛。
7. 发布前复核冻结源清单和安全目标边界，逐项再检查版本与父目录身份。不得在发现目录被替换/移动后把新目录默认为先前创建或授权对象。
8. 新普通文件在目标父目录内暂存、校验、同步后不覆盖发布；复制不改写源。文件保留普通rwx权限而不传播特殊权限；新目录采用私有可操作权限，不承诺源目录元数据、ACL/xattr或硬链接拓扑的完整镜像。
9. 目录复制不是跨文件原子事务。冲突、取消、源变化、保存失败或未知立即停止余项；已经完成的目标保留，不自动删除伪装回滚，不将单个成功项冒充整棵树成功。
10. 每个可能发生副作用的项在执行前有已确认的意图记录，执行后保存执行器实际结算。分段日志独立于小dirty摘要与聊天上下文，不通过增大/裁剪旧32项日志或自动重放突破限制。
11. 逐项回执包含源/目标实际位置、冻结版本、文件实际结果hash/字节数及完成/未变更/未知/未尝试状态。总体状态、实际执行进度与结算保存可用性分别报告；保存失败不得抹去本进程已知实际结果。
12. 持久Session的清单与分段回执使用同Session认证加密及独立版本，遵守provider预检、在用锁、delete/clear密钥撤销。未知写入不盲重试，不从孤儿片段推断已执行或提升未确认保存范围。
13. 重启只读恢复已认证计划和结算；仅有执行前意图的项为unknown，后续未开始项为not_started。恢复不继续复制、不恢复批准、不重放历史调用；同一已记录调用身份不能再执行一遍。
14. --no-save仅在有界内存保留自动日志，不创建明文/加密历史侧车；复制明确产生的目标和必要内部暂存属于文件操作副作用。取消/清理失败须报告残留或未知，不以“不保存”回滚文件。
15. 复制字节、清单与项数预算集中可配置，new/resume/F2使用当前客户端设置。容量不足尽可能在授权前拒绝；执行途中持久化配额不足时保留真实前缀并停止，不无限分配或自动淘汰事实。
16. 验收涵盖真实超过32MiB二进制、超过32项及大目录清单、嵌套/空目录、权限/链接/别名/目标冲突、授权后变更、逐项取消/保存故障、模型与客户端可见结果、加密恢复/清理和no-save。支持Linux/macOS；交叉编译不替代原生运行证据。

不在本单元：目录合并/覆盖、源链接复制或跟随、跨文件事务/自动回滚、完整元数据镜像、自动恢复执行、归档恢复/清理、Windows产品支持。后两项归档能力分别由C9/C10交付。
