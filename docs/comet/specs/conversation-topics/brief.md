# Shape：对话话题索引与长对话压缩

状态：Shape 已确认（2026-10-18）。依据 [#117 正文及确认评论](https://github.com/ErzerLP/edu-agent/issues/117)，依赖 [用量统计](../model-usage/brief.md)，向 [Studio](../studio-staged-generation/brief.md)提供话题范围。

## 结果

对话变长后仍能继续。用户从工具栏的小入口查看聊过的话题、要点和理解情况，并跳到相关消息；之后可以选择几个话题整理为笔记或复习测验。

## 范围

- 只读话题索引：话题名、要点、理解状态、相关消息位置；消息和话题为多对多关系。
- 每隔若干轮增量整理新增消息；压缩时给模型话题要点和状态，以及按上下文窗口比例保留的最近原文。
- 后台整理失败时对话继续，只带最近原文并提示“较早内容未纳入”。
- 保留原始对话、练习及学习记录；提供按话题选择范围的读取契约，整理产物入口在后续 Studio child 实现。

## 非目标

- 不把对话按轮次显式切段，不允许用户编辑摘要，不把话题做成另一套笔记。
- 不让摘要改成绩或掌握度，不生成长期记忆，不重读其他学习区或绕过来源选择。
- 不修改 CLI 的上下文压缩，不建设向量检索或 #111 的整本书导入。

## 关键决定

| 决定 | 行为 |
| --- | --- |
| 索引按话题 | 一个话题可散布在多处，一条消息可关联多个话题；“上一处／下一处”按消息顺序定位。 |
| 只处理新增内容 | 已提交的整理水位向前推进；更新已有话题只结合其已存要点与新增消息，不重新扫描旧原文。 |
| 自动压缩 | 触发和原文保留量从 `context_tokens` 派生；用户不填写轮数或 Token 预算。 |
| 摘要不是学习结论 | 状态反映对话中的理解情况；练习标注“练习结果以学习记录为准”，不因摘要写“弄懂了”改变进度。 |
| 安全降级 | 摘要失败不改旧原文、不阻断正常后续交流；原文被省略时说明“较早内容未纳入”。 |

数据模型、来源隔离、上下文计算和分批计划见[设计](../../../design/conversation-topics.md)，可观察合同见 [spec](spec.md)。

## 端到端验收示例

- 对话先聊 TCP，再聊子网，之后回到 TCP。一条比较消息同时出现在两个话题的位置列表中，点击 TCP 可逐处跳转；索引不强行把对话切成三段。
- 对话总长度超过模型窗口后继续提问较早聊过的要点，模型能使用相关话题摘要；历史仍能逐页查看，已有练习答案和反馈不变。
- 一次摘要服务失败，用户仍能继续交流，看到“较早内容未纳入”；后续整理从原水位补上缺口，不冒充此前已成功。
