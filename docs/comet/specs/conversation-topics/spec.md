# Capability：对话话题索引与长对话压缩

状态：Shape 已确认（2026-10-18），不表示已实施。参见 [brief](brief.md) 与[设计](../../../design/conversation-topics.md)。

## 合同与验收

1. 每个对话拥有自己的话题索引，记录话题名、要点、理解状态和对应消息；同一条消息可属于多个话题，同一话题可出现于不相邻位置，不按轮次向用户显式切段。
2. 新消息按周期增量归入已有话题或新话题；已经成功整理的原文不会在每轮被重新处理，失败的区间不冒充已覆盖。
3. 对话工具栏提供小入口，展开为话题列表；能区分尚未整理、整理中、已有结果和暂时失败，不显示虚构话题。
4. 点击话题跳到实际相关消息，多处时支持“上一处／下一处”；目标不在已加载历史中时可加载对应位置，不跳到另一个对话或相似消息。
5. 用户可以查看话题摘要及理解状态，不能编辑它们。摘要更新、合并展示或上下文裁剪不会改写、删除原始消息和学习记录。
6. 理解状态表达对话中的观察，不等于掌握度；涉及练习时提示“练习结果以学习记录为准”，不能将未提交或未评估练习说成已通过。
7. 合法单次输入和模型配置下，历史累计超过 `context_tokens` 仍可继续对话，不因完整历史体积或旧 checkpoint 大小上限失败。
8. 长对话模型输入包含可用的话题要点与状态以及最近原文；触发时机和原文保留量按上下文窗口比例自动计算，用户无需设置切段轮数或预算。
9. 组装请求计入系统提示、工具定义、来源、输出预留及安全余量，不发送已知超窗请求；工具调用与其结果不因裁剪变成不完整消息组。
10. 话题数量增长时，模型投影仍有界，优先包含与本次问题相关的话题；索引界面和原文位置仍可查看，不能把未送入模型的话题假装全部已纳入。
11. 需要压缩而摘要失败或来不及完成时，继续使用可容纳的最近原文，显示“较早内容未纳入”；不使用失败输出或偷偷扩大来源作为替代。
12. 摘要失败不推进整理水位、不破坏上一次可查看结果；恢复后可从未整理部分继续，不要求用户重建对话。
13. 话题及最近原文作为模型输入时遵守本次来源、学习方向及外发授权；未选来源不能借旧摘要、练习或引用重新进入请求。
14. 摘要不能写入 Attempt、Assessment、Evidence 或长期记忆；学习进度、练习反馈仍读取原有事实。
15. 后续“整理本次对话”可读取用户选定话题的有界投影；未选择话题及不在授权范围的内容不能混入，该投影不能充当资料引用。
16. 摘要模型调用进入用量台账，可从该对话追溯；没有产生外发的索引读取不增加调用次数。
17. 旧对话不因升级或仅打开页面而自动外发；只有用户继续该对话、主动“整理话题”或使用“整理本次对话”时，才在当前授权范围内分批补建，显示整理进度和尚未覆盖范围。临时对话不因话题功能变成永久保存。
18. 并发整理、重复事件和服务重启不会重复建立同一锚点或覆盖较新的话题结果；当前轮次可以与后台整理并行，读取最后一次完整提交的索引。
19. 对话删除、权限撤销及隐私清除使其派生话题和位置失效；清除后迟到摘要、缓存或模型响应不能恢复旧内容。
20. 工具栏、话题列表和位置切换可用键盘操作，跳转后有明确焦点；移动端可返回原话题列表，对话和 Studio 的未发送输入不被导航丢弃。

## 交付与证据
