# 可选学习规划

已有结构化目标可以进入独立规划页面。模型不是目标创建、草稿保存或编辑的前置条件。澄清复用已填字段，允许跳过、取消和直接编辑；对话建议与表单共享 PlanningContent。

规划草稿、模型 suggestion 与正式目标是不同实体。草稿保留目标原文及版本、自述、模型建议、资料范围和适用会话版本。模型只产生闭合结构化建议，不能写入 Evidence、mastery、复习日期或教学状态；确认前不改变正式目标或教学事实。

资料只能来自 #3 的冻结范围。页面以名称展示阶段、内容、理由、前置关系、练习、完成依据和可查看的章节引用。覆盖分析明确输入上限和不确定性；无引用建议可以保存，不能应用为可直接出题评分的路线。模型不能自行扩大资料范围。

保存与确认均由服务端校验关系、引用、有效状态和版本。目标版本、资料集合版本或适用教学状态变化时显示过期原因并拒绝旧草稿覆盖新事实。用户可新建草稿，重新选择范围并核对。

明确确认可以只修订目标、采用到新会话或采用到原会话后续步骤；不得自动选择用途。正式操作复用 #4/#5 应用服务，在同一事务中保存业务结果与幂等回执。失败回滚全部正式变更，重复提交返回原结果，不重复创建路线。已有题目、作答、评估和证据不变。

模型沿用服务端适配、错误分类及凭据边界，页面声明配置来源。超时、非法结构、越界引用或取消保留可恢复草稿和真实错误结果。客户端不保存额外明文学习内容；草稿及回执遵循 learning 隐私清除与无正文重放规则，不写长期个人记忆。

验收分别记录领域/HTTP/CLI 测试、真实 PostgreSQL 与结构化模型 fixture 的生成—编辑—确认—按目标开始学习，以及真实模型效果。没有运行的真实模型或原生终端检查不得以 fixture 代替。
