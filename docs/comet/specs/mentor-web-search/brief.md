# Shape：网页导师联网搜索

状态：Shape 文档定稿（2026-10-20），未实施。依据 [#165 正文及 S1/S2 确认](https://github.com/ErzerLP/edu-agent/issues/165#issuecomment-6290213764)；拆分与依赖见 [Supervisor](../../../design/search-shape.md)。

## 结果

网页导师在需要新信息或补充资料时自行搜索、读取网页，再给出可核对的回答。用户能关闭联网，也能把回答引用的网页加入当前学习区来源。

## 范围

- 在导师对话输入区保留“联网搜索”开关，默认开启；按对话记住。用户发送问题后自动判断是否需要搜索，不逐次弹窗确认。
- 搜索和正文读取分别执行；支持现有安全抓取器可读的 HTML、Markdown、文本及文本层 PDF，准确说明读取缺口。
- 回答中的“网络来源”与“学习区来源”区分展示；只有实际读取、校验过的正文能作为网络引用。
- 网络引用提供“加入来源”，用户确认后才写入当前学习区；不自动采用，不扩大当前对话的来源选择。
- 同时覆盖选中学习区来源、没有选中来源的普通导师问答路径；练习评估及 Studio 生成的资料约束保持各自合同。
- 搜索次数、模型用量、停止、工具步数与隐私清除进入现有运行和台账体系。

## 非目标

- 不新增 CLI 工具，不修改 CLI 的目标研究或模型协议。
- 不在此 change 实现多方向智能搜集、候选批量导入和整理报告；由后续 `source-research` 交付。
- 不做登录网页、动态浏览器、付费墙绕过、OCR、整本 PDF 阅读或新的 PDF 解析器。
- 不保留被本 change 替换的接口别名，不转换旧数据，不建设累计预算或计费系统。

## 关键决定

| 决定 | 行为 |
| --- | --- |
| S1，用户已确认 | 导师自动判断；开关默认开启。关闭阻止此对话后续搜索与网页抓取，并取消在途网络请求。 |
| S2，用户已确认 | 搜索结果不自动成为来源；网络引用附“加入来源”。 |
| 外发范围 | 检索从用户本次输入提炼关键词；网络检索上下文不加载私人来源、成绩、记忆或完整对话。对话开关不代表关闭正常的模型回答。 |
| 引用身份 | 网络正文快照与正式知识来源分开；导入后旧回答仍指向当时读过的版本。 |
| 导入 | 点击按钮打开预览，确认保存；重试不重复创建来源，不自动更新同名或同 URL 的历史版本。 |
| 共享基础 | 抓取、网络引用、保存预览和搜索计数随本结果交付，后续智能搜集复用。 |

详细合同见 [spec](spec.md)，工具、API、存储与批次见[设计](../../../design/mentor-web-search.md)。

## 拆分与 Ready

本 change 是 Supervisor 的第一个 child，22 条验收，一个垂直批次 **M-A：自动搜索 → 网络引用 → 手动加入来源**。设置、外发门禁、PDF、台账与清除都随该闭环交付，不拆出只能提供底层类型的基础 child。后续 `source-research` 依赖其公共合同；共享 schema 和路由串行修改。

已明确数据 owner、接口草案、数据库结构变更和退出标准，无阻塞产品问题，可进入 M-A Build。本次只写文档，未创建 Runtime 状态或验证记录。

## 端到端验收示例

- 用户询问某框架的新版本差异，导师自行搜索并读取正文；回答里的网页显示“网络来源”，既有教材显示“学习区来源”。用户查看原文后确认加入，来源列表才出现新资料。
- 用户在抓取期间关闭“联网搜索”，新的搜索、后续跳转和读取不再派发，在途请求取消；已读内容仍可用于回答，界面说明搜索已停止，已发生用量保留。
- 返回 PDF 时展示读到的页和缺口；只能引用实际提取的片段。没有可读正文时说明原因，不拿搜索摘要冒充正文。
- 同一“加入来源”操作响应丢失后重试，只得到原导入回执。删除对话或清除隐私后，旧网络快照和 PDF 不能经旧链接重新读取。
