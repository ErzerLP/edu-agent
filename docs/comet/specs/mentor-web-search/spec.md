# Capability：网页导师联网搜索

状态：Shape 文档定稿（2026-10-20），未实施。结果见 [brief](brief.md)，协议和批次见[设计](../../../design/mentor-web-search.md)。

## 合同与验收

1. 网页普通导师对话提供“联网搜索”，新对话默认开启，选择按对话保存；发送前可看到当前状态和简短外发告知，不要求每次搜索另行确认。
2. 开启时导师根据问题决定是否搜索，既支持补充所选来源，也支持未选来源的问答；不要求用户切换到独立研究页面。
3. 关闭后服务端拒绝该对话新的搜索、抓取和重定向请求，取消已在途的网络请求；旧许可、其他标签页或旧 worker 不能继续派发。已经外发的请求无法撤回，已读取结果与用量不会伪装为未发生。
4. 开关只管理此对话的网络检索；关闭后正常模型回答仍可使用已获授权的学习区资料及已保存网络片段。重新开启不自动重启先前被停止的搜索。
5. 搜索只向已配置的搜索服务发送必要检索词；网络检索上下文不得加载学习区正文、学习记录、长期记忆、本机工具结果或完整聊天历史。不足以形成公开主题时允许普通澄清，不静默拿私人材料补题。
6. 搜索未配置、被禁用或失败时明确说明不能联网；不静默更换提供商，不伪造已搜索或已读网页，也不使普通对话失去使用已有资料回答的能力。
7. 搜索摘要只用于选择待读页面。只有实际读取并保存的片段可作事实引用；未读取、读取失败、被禁止保存或超出覆盖范围的内容不能获得有效引用。
8. 搜索、网页读取及其他导师工具共同受 `Limits.MaxToolSteps` 约束，默认不限；每个工具调用分别计数，达到已配置上限时说明进展，用户继续后才重开工具轮次。模型调用、HTTP 跳转数和工具次数不混为一项。
9. 网络页面和 PDF 沿用安全抓取与解析边界，拒绝私网、危险跳转、非允许格式、超限及受限制内容；不执行页面脚本、PDF 脚本或页面要求的操作。
10. 搜索结果、页面正文和元数据均是不可信数据；不能改变用户授权、增加工具、修改目的地、写知识、批准操作或读取其他学习区。服务端对每次执行重新核验权限和范围。
11. 网络引用与学习区引用有可机器辨别的类型及用户可见标签；同一回答可同时包含二者。网络引用不能伪装成正式知识身份，不能扩大所选学习区来源范围。
12. 网络引用绑定当时读取的地址、时间、正文版本及具体片段；查看引用能核对原文、读取缺口和 PDF 物理页码。网页后来变化不改变历史回答的引用。
13. 引用验证只证明片段确实被读取及位置相符，不代表网页事实可靠。无效引用不得作为有效证据发布；回答区分资料事实、推断及未核实内容。
14. 每个可保存网络引用提供“加入来源”，先预览后由用户确认；加入前不进入正式来源、索引、目标参考或掌握度记录。
15. 导入只能使用服务端核验过的当前快照，不能信任客户端提供的正文、页码、地址替换或引用身份。PDF 复用已有解析与保存流程，存在部分提取时必须明确接受可用文本。
16. 导入为当前学习区私有的新来源，重复操作返回同一结果；同一快照已导入时指向已有来源，不能悄悄覆盖同 URL／同名资料。导入不自动勾选为当前问答资料，旧网络引用保持原类型及版本。
17. 停止导师运行后不再派发网络或模型请求；停止、关闭联网、删除、撤权与迟到响应交错时，过期结果不能重新写入或恢复执行。
18. 所有模型调用，包括联网判断、检索规划、整理、修复及进展说明，进入现有 `modelusage` 台账；受单次输出和上下文窗口硬限制，不设累计 Token、请求或金额预算。
19. 每次实际搜索提供商 HTTP 请求独立计数并归入原任务，失败或取消仍保留已外发事实；未派发不计数，未知结果明确标记。搜索次数不冒充模型调用或 Token，读取网页数另外展示。
20. 网络正文、查询、引用和 PDF 原件按对话／运行的保存周期加密保留，删除与隐私清除涵盖所有副本和缓存；正式导入的来源由 knowledge 管理，清除对话不隐式删除已导入资料，全局清除覆盖两者。
21. 引用、预览、导入、进度和用量均执行当前学习区、真实身份和隐私代次检查；跨区 ID、旧回执及已撤权凭据不能读写正文。新路径在部署白名单中可达且不扩大任意代理能力。
22. 开关、引用查看和加入来源可用键盘与移动端操作；进度、关闭状态及错误可被辅助技术读取，用户文案不暴露租约、scope、checkpoint 等后台术语。
