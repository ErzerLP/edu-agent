# Shape：用量统计与取消任务预算

状态：Shape 已确认（2026-10-18）。来源为 [#118 及确认评论](https://github.com/ErzerLP/edu-agent/issues/118)；作为 [Supervisor](../../../design/learning-generation-shape.md) 的第一个 child，先于 #117 和 #118 的生成改造。

## 结果

用户不用猜本次任务需要多少 Token。任务不再因累计请求或 Token 预算用尽而暂停；用户可以停止任务，并在独立用量页查看每次生成、各学习区和全局的 Token 消耗。导师对话、研究等可设置每轮工具调用上限，默认不限；达到自设上限时说明进展，用户点击“继续”后接着执行。

## 范围

- 取消对话、研究、Studio、评估等服务端任务的请求次数和 Token 预算，以及设置、表单中的相关输入和“增加预算继续”流程。
- 单独用量页提供输入、输出、推理 Token 和模型调用次数，支持单次明细、学习区累计、全局累计，以及日／周／月和模型筛选。
- 覆盖服务端全部模型出口，包括规划、重试、研究综合、知识处理、评估和话题整理；统计失败和停止前已经发出的调用。
- 台账首版预留来源（web／cli／server 后台任务）和设备归属；CLI 本地直连不统计，页面注明范围。
- 设置新增“每轮工具调用上限”，默认不限、可设正整数；到达时收回工具，最后一步说明进展与缺口，等待用户点击“继续”并重新计数。此项与 Token 统计无关，不限制 Studio 分段生成。
- 兼容旧请求中的预算字段和旧暂停任务；不修改 CLI 命令、提示或本地模型协议。[#122 模型网关](https://github.com/ErzerLP/edu-agent/issues/122)另做 Shape，安排在本 child 之后。

## 非目标

- 不换算金额，不做账单、充值、配额、告警或供应商用量对账。
- 不取消单次输出上限和上下文窗口，不取消授权、并发、超时及存储限制。
- 不推算历史缺失用量，不以输入估算值冒充真实统计；长上下文处理由后续两个 child 交付。

## 关键决定

| 决定 | 行为 |
| --- | --- |
| 只统计，不限累计用量 | `research_requests`／`research_tokens`、`request_budget`／`token_budget` 不再决定能否执行。 |
| 不确定就说明 | 字段缺失、超时或连接中断时显示“未知”；汇总可展示已知合计和未知调用数，不显示假零。 |
| 推理属于输出明细 | 推理 Token 已包含在输出内时不再相加。协议适配保持统一口径。 |
| 调用与生成分开 | 一次生成可以包含规划、分段和修复等多次调用；一个真实外发尝试只入账一次，查询和重放不增加用量。 |
| 清除保持一致 | 用量明细与关联学习数据同属隐私范围；清除后不保留可重新识别旧活动的汇总。 |
| 工具上限由用户选择 | 默认不限，不默认启用重复调用检测；设置上限后暂停说明并可继续，不恢复请求或 Token 预算。 |

数据模型、旧 API 兼容、恢复规则和分批计划见[设计](../../../design/model-usage.md)，完整可观察行为见 [spec](spec.md)。

## 端到端验收示例

- 用户发起 Studio 生成，界面没有预算输入；在用量页看到同一生成下的多次调用、各模型的已知 Token，以及某次超时的“未知”。取消后已发生的消耗仍保留。
- 同一区的对话、研究和评估用量进入区累计，全局可以按月和模型查看；重开页面或核对原操作不会重复计数。
- 旧客户端仍携带很小的预算值，服务端不会因该值暂停；升级前已暂停的任务等待用户继续，不在升级后自动外发。

## 用户已确认（2026-10-18）

| 编号 | 问题 | 已确认的决定 |
| --- | --- | --- |
| U1 | 统计哪些调用，如何衔接 CLI？ | 本轮统计所有服务端发起的模型调用，包括 CLI 发起的服务端任务；CLI 本地直连不统计，页面注明。台账从首版起预留来源和设备归属，使 #122 接入同一台账时无需再改数据库结构。 |
| U2 | 是否限制每轮工具调用？ | 默认不限，可设正整数；达到上限时收回工具，最后一步用文字说明进展和缺口，点击“继续”后重新计数并接着执行。此项不是预算，与 Token 统计无关，不影响 Studio；不做默认生效的重复调用检测，以后可另设可选项。 |
| #122 | CLI 后续如何接入？ | 服务端做模型网关，CLI 默认经网关调用，同时保留不统计的本地直连模式；CLI 与网页共用工具调用上限设置。独立 Shape 在 model-usage 之后，本轮只交付台账字段与设置衔接点，不实现网关或 CLI 改造。 |
