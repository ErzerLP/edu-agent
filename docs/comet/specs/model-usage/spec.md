# Capability：用量统计与取消任务预算

状态：Shape 已确认（2026-10-18），未表示已实施。结果、范围与已确认决定见 [brief](brief.md)，协议与实施细节见[设计](../../../design/model-usage.md)。

## 合同与验收

1. 对话、研究、Studio、评估及其他服务端模型任务不因单次任务累计请求或 Token 预算停止、拒绝或暂停；用户无需填写预算。可选的每轮工具调用上限按第 21–23 条执行。
2. Web 设置与任务入口移除相关预算输入、余额和“增加预算继续”操作。单次输出与上下文配置、并发、超时、存储和权限仍有效。
3. 单次模型请求遵守配置的输出上限和上下文窗口；取消累计预算不能发送已知超窗请求。长历史与大来源的适配由 T/S 合同约束，U 不声称已单独完成压缩或分段。
4. 用户可以沿任务既有停止入口中止后续工作；已发送调用的消耗不因停止、失败或结果不采用而消失。
5. 独立用量页提供输入 Token、输出 Token、推理 Token 和调用次数，不展示金额。推理已包含在输出时明确其为“其中”，不重复计入总量。
6. 模型未返回某项用量时该项显示“未知”，不能由估算、其他字段缺失或默认零构造精确值；明确返回的零可显示为零。
7. 汇总保留各项已知合计和未知调用数；存在未知项时不能把已知小计标成完整总量。
8. 一次生成明细列出其模型调用与阶段、时间、模型和状态；后台话题整理有可追溯的任务明细，并与相应对话关联。
9. 学习区累计包含区内各项任务；全局累计包含所有获准查看的学习区和无学习区归属的服务端模型调用。同一条调用在任一汇总中只计一次。
10. 用户可按日、周、月及模型查看统计；同一时区和筛选条件下，明细和汇总口径一致，页面说明当前时间边界。
11. 所有服务端发起的模型调用均纳入统计，包括对话、研究、Studio、评估、摘要、知识处理及模型连接探测；CLI 本地直连不统计，页面明确范围。台账首版即保留来源（web／cli／server 后台任务）及设备归属，供后续 CLI 网关调用直接使用同一结构。
12. 协议回退、自动重试和用户重试发生新的外发时分别计数；读取状态、重复提交同一操作、恢复已保存结果不产生新的调用数。
13. 超时、断线和服务重启不能把结果未知的调用显示为无消耗或成功；后来获得可核对用量时更新原调用，不新增一条重复记录。
14. 统计只记录必要计数和归属，不保存提示词、回答、隐藏推理正文、来源内容或认证秘密。
15. 旧客户端携带合法旧预算字段仍可使用；省略这些字段的新请求可使用。字段数值不再限制执行，但不放松其他格式、权限和幂等校验。
16. 旧的预算暂停任务在升级后仍等待用户动作；旧“继续预算”请求兼容为继续执行，不能借此自动接受外发目的地变化或复活已清除任务。
17. 已存在的任务、结果及操作回执可读；没有可靠用量的历史任务显示“未记录／未知”，不从旧余额推导真实 Token。
18. 统计范围服从身份和学习区权限，不能通过全局聚合获取无权查看活动的明细；页面缓存及迟到响应受隐私代次隔离。
19. 隐私清除使相关调用明细、关联和汇总失效；旧 worker 不能重新写回或返回已清数据，清除后统计不混入上一代数据。
20. CLI 既有服务端请求和共享模型循环协议保持兼容；本 child 不要求更新 CLI 才能继续学习。[#122](https://github.com/ErzerLP/edu-agent/issues/122)在本 child 后独立 Shape：CLI 默认经服务端模型网关调用，进入同一台账；保留不统计的本地直连模式，网关与 CLI 改造不纳入本 child。
21. 设置提供“每轮工具调用上限”，默认不限，可配置为正整数，适用于导师对话、研究等 agent 工具循环；默认不限时不会因工具调用步数停止或暂停，也不默认启用重复调用检测。
22. 设置了上限且到达时，收回工具，最后一步由模型用文字说明当前进展和还缺什么，暂停等待用户；界面提供“继续”，点击后重新计数并接着执行，不要求增加预算。
23. 工具调用上限与 Token 统计无关，不能恢复累计请求或 Token 预算；Studio 分段生成的步数由确认后的大纲决定，不受此项影响。#122 落地后 CLI 与网页共用此设置，本 child 只确定设置衔接点。
