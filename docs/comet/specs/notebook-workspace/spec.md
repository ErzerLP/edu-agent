# Capability: Notebook 式学习工作区

结果：用户在一个与 learning space 对应的 Notebook 式工作区中，以来源为依据完成目标教学闭环，并整理 Studio 产物；原辅助功能和既有数据语义继续有效。

状态：Shape 待确认。带【D1】至【D4】的条款按 [brief](brief.md) 中的建议默认值书写，**默认，待用户确认**；相关 child 在确认前不得进入依赖这些条款的 Build。其余条款是本次提交审阅的正式合同草案。布局令牌、文件拆分、接口方案和测试命令放在[设计文档](../../../design/notebook-workspace.md)，不在此复制。

## 合同与验收

### 入口与导航

1. 配对成功后的 Web 首页显示真实学习区卡片墙，支持创建、搜索、状态筛选和分页；区分加载、空结果、失败与能力不可用。卡片名称及元信息来自真实数据，不以假数量或不完整分页冒充总量。创建成功后进入新学习区，失败保留输入且不创建假卡片。
2. 一个笔记本对应一个现有 learning space，改名、归档、恢复沿用其版本和权限规则。归档区可按权限查看历史，禁止新增课堂、来源或产物等写入；恢复后重新核验能力。现有目标的搜索、筛选、分页、编辑、生命周期与修订历史仍可到达。
3. 桌面学习区显示左“来源”、中“课堂”、右“Studio”，顶栏保留返回首页、学习区名称和菜单等主要入口。中栏的目标与课堂是主要学习路径；辅助功能进入左上侧边菜单，不再以顶部长导航挤占主界面。
4. 菜单可到达进度与复习、评估与证据、导师历史、长期记忆、任务中心、知识结构与维护、NoteSync、离线、设置、数据与设备，以及原内容库。保留原深链接及其学习区、目标、会话、内容版本和筛选上下文；直达、刷新及浏览器前后退可用，不丢弃参数或静默跳到默认区。
5. 【D4】无目标学习区可管理来源、进行来源问答、生成指南／简报和保存笔记。课堂与正式测验要求用户明确选择或建立目标；缺目标、缺模型、缺来源和缺权限分别说明。不得为浏览、导入、勾选或打开学习区隐式创建目标、课堂或模型任务。

### 来源与可追溯回答

6. 来源列表呈现当前区获准访问的正式资料；候选、处理中、失败、部分正文和已保存分别可辨认。多个集合中的同名文档不混同；旧资料没有类型或覆盖元信息时显示未知，不伪装为完整网页或已解析 PDF。
7. “添加来源”提供 PDF、文本、网址、搜索发现四个入口。导入前可审阅实际内容／解析报告与变更，正式确认才保存；身份冲突、范围变化和失败不得被一步“添加成功”遮盖。导入到区内与正式采用为课堂参考是不同动作。
8. PDF 上传保留原件保存授权、资源／页数限制和逐页缺口报告；部分解析须明确接受可用部分，扫描／空白／失败页不计为已读。文本保留用户原文及编码检查；失败项不加入可选正式来源。查看 PDF 通过受控页图和文本定位，不向浏览器开放未经校验的原件执行。
9. URL 抓取及搜索前明确所发送的公开地址／关键词与外部请求授权；不得自动发送私人目标、笔记或成绩。搜索结果只作候选摘要，用户选中后读取正文并审阅保存；未读取、禁止保存或读取失败的摘要不能用于课堂或生成引用。沿用公开网络、重定向、格式、大小、超时与预算边界。
10. 【D1】左栏勾选只决定以后发起的来源问答和 Studio 生成输入，发起时冻结确切来源及版本；进行中的运行和课堂不随勾选漂移。界面分别说明本次所选来源与课堂已冻结资料。勾选不修改目标／课堂参考政策，也不隐式共享或发布 NoteSync。
11. 【D1】导师对“基于所选来源”的回答由服务端限定资料范围；未勾选资料不能经历史、其他工具或跨区查询进入资料上下文。改变选择后，旧回答可保留并标明旧范围，新请求不得把不兼容的旧资料上下文继续外发。零来源时明确为无来源交流，不伪造引用；依赖资料的生成应阻止并提示补充来源。
12. 课堂、导师和 Studio 中的资料引用可打开对应历史版本与片段，提供文档／章节／段落或实际 PDF 页位置及覆盖缺口。引用必须由服务端验证归属、范围和原文一致性；未知、被清除或失去权限的来源显示不可用，不替换成最新版本或仅凭模型 URL 当作依据。手机定位后可返回原活动和焦点。

### 中栏教学与 Studio

13. 中栏可选择／建立目标、选择／恢复课堂，并继续既有讲解、练习、评估、复习与教学变更流程。发起课堂前用户能核对采用资料；发出活动的目标、资料、题目、rubric 及版本继续冻结。后续参考／教学调整保留现有预览、确认和安全接入规则，不能通过新布局重置原会话。
14. 正式答案使用独立控件并由用户提交；聊天、快捷追问和笔记不会自动成为答案。帮助等级须明确选择且受活动 allowed_help 约束，提供帮助后不得降级谎报独立完成；快捷操作与 IME、Enter／换行行为保持这一边界。
15. 反馈、路线进度与到期复习只展示正式后端记录；已完成步骤与掌握状态分别说明，未知分母不画百分比。provisional／不完整／降级／待复核有可见说明；生成测验、阅读、聊天或手动完成本身不产生 accepted Evidence。
16. Studio 首页提供四种产物入口和已保存列表，可打开指定结果并返回列表。每项可辨别类型、标题、真实状态及创建时的资料范围；指南／简报／测验的排队、生成、部分、失败和完成依真实服务端结果显示，失败可核对和重试，不显示模拟完成时间。
17. 学习指南以所选资料组织核心概念、学习顺序／重点和常见误区，标明资料支持的部分与生成建议；简报聚合主要结论、来源差异及覆盖缺口。二者保留可核验引用、输入版本和历史结果，不能把研究综合或旧课堂阅读内容改名便视作完成新生成。
18. 【D2】Studio 测验展示题目并绑定用户明确选择的目标及冻结资料；用户确认后进入正式作答流程，逐题答案、实际帮助等级、评估与回执沿用教学领域。只有正式记录按既有规则计入进度；同一提交不重复计分，评估待确认不伪报通过；打开测验不覆盖另一进行中课堂或其草稿。
19. 笔记支持手动创建、编辑、明确保存和再次打开。保存前为本标签页草稿，保存后为学习区内受权限与隐私保护的版本化产物；保存失败或版本冲突保留输入，不能静默覆盖他人的新版。笔记不是长期记忆、成绩或正式外部依据。
20. 【D3】“转为来源”先指定已保存笔记版本并审阅导入结果，确认后产生单独文本来源及笔记版本出处；重复核对原操作不重复导入。之后编辑笔记不会改写已导入来源，来源按普通选择／采用流程才能影响导师、Studio 或后续课堂，不能自动升级为权威证据。
21. 已保存产物可在重开学习区后读取；重新生成形成可辨别的新结果／版本，不能覆盖原题答案、旧引用或历史产物。生成取消、超时、服务重启、预算用尽、响应丢失时保留真实状态和恢复入口；尚未确认的操作结果先核对，不自动重复提交。

### 安全、隔离与兼容

22. 所有读写继续受配对档案／设备 scope、Cookie 会话、CSRF、精确 Origin、学习区／集合归属及服务端能力检查保护。界面禁用只是提示；服务端不得因 Notebook 入口、来源勾选或生成而放松已有权限和校验。模型输出及来源正文不能成为授权指令。
23. 在线未提交答案、提示词、来源导入和笔记草稿只在当前标签页内存中；同一标签页切面板／路由可恢复，刷新前提示丢失。不写 localStorage、sessionStorage、IndexedDB 或 Service Worker 缓存。明确保存到服务端的产物与既有用户授权的加密离线库各遵循其原合同。
24. 缓存、草稿、订阅和请求按服务端 origin、设备 principal、隐私 generation、学习区以及目标／会话／产物版本隔离。切区、退出、失效、撤权及隐私清除后隐藏受保护正文，取消订阅／请求，迟到响应不恢复旧正文或覆盖新草稿。新产物、索引和来源派生关系须纳入对应 owner 的清除与验证。
25. 正式写入沿用 expected version、操作身份和请求内容绑定的幂等语义；同操作同载荷返回原结果，不同载荷冲突。未知结果、版本冲突和失效批准有明确恢复步骤；不得靠前端重新编号、吞错或伪造成功绕过服务端门禁。

### 手机、可访问性与发布

26. 窄屏用底部“来源／课堂／Studio”标签访问同一工作区，默认进入课堂；切换不丢失未提交草稿或重复订阅运行。长标题、代码、公式、对话框、软键盘及安全区域不导致整页横溢出或遮挡主要操作；被隐藏面板不可被键盘误入。
27. 菜单、对话框、标签、来源勾选、引用返回和正式作答均可键盘操作，有可读名称、可见焦点、状态播报和正确焦点恢复。沿用浅／深主题能力；文本、边界和状态满足现有可访问性验收标准，状态不只靠颜色区分；危险确认默认聚焦取消。
28. 新流程具有真实后端浏览器验收；旧路由仍承担原有业务回归，调整定位不能删除安全、幂等、隐私及正式作答断言。候选继续通过现有 Web 发布门禁、真实资产／深链接边界和跨浏览器矩阵；未执行或被跳过的数据库／浏览器检查不得记为通过。CLI 产品行为保持兼容。
