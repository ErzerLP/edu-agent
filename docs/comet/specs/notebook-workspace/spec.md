# Capability：在 AI 对话中学习的 Notebook 式学习区

状态：Shape 已确认（2026-10-13）：用户认可对话式原型 v2，Q1–Q5 采用建议默认值。

结果：用户围绕一个可调整的学习方向，在学习区的 AI 对话里依据所选来源学习、完成练习和查看反馈，并整理 Studio 产物。后台继续使用既有学习记录与证据规则。

本合同描述归档后的完整可观察行为，**不表示新方向已实施**。批次 1–3 已交付的来源、引用、Studio 与安全能力继续作为回归要求。方向决定见 [brief](brief.md)，协议、状态矩阵、owner、migration 与计划见[设计文档](../../../design/notebook-workspace.md)。Q1–Q5 已由用户确认采用建议默认值（2026-10-13）。

## 合同与验收

### 学习区与方向

1. 配对后的首页显示真实学习区卡片墙，支持创建、搜索、状态筛选与分页，区分加载、空结果、失败与能力不可用。卡片不展示伪造数量、进度或最近学习时间；创建失败保留输入，不产生假卡片。
2. 创建学习区时填写名称与学习方向，方向允许宽泛，在学习区设置里可修改。保存使用版本冲突规则，不静默覆盖他人修改；改名不改变方向。已有区首次启用新对话时按 Q1 补方向，来源、旧会话与旧成绩保留，不从私人旧内容自动推断并外发。
3. 用户无需手工选择、创建、搜索或管理教学目标。系统只在已授权学习动作需要时依据真实方向建立／修订后台目标；仅浏览、导入、勾选或打开页面不启动模型或创建教学活动。方向变化用于之后受理的学习请求，已出的题、评分标准与历史记录保持原版本，不自动继承为新方向已掌握。
4. 桌面为左“来源”、中“对话”、右“Studio”，顶栏保留返回、名称、学习区设置及菜单。中栏移除“今天想学会什么”、目标选择／建立、目标搜索分页与开课步骤；不出现关于“正式／冻结／档案”的后台术语或常驻解释性文案。错误恢复、外发授权和必要审阅须保留简明可执行入口。
5. 学习区仍对应原 learning space；归档、恢复、改名沿用原权限与生命周期。归档后可依权限查历史，禁止新对话轮次、练习提交、来源及产物写入，恢复后重新核验能力。菜单保留进度与复习、评估与证据、导师历史、长期记忆、任务、知识维护、NoteSync、离线、内容库、设置、数据与设备。
6. 旧学习区、目标、课堂、对话、内容版本及辅助页深链接可直达、刷新、前进后退，保留身份与筛选，不静默改成另一个会话或默认区。旧目标管理仅为历史兼容入口，不成为新学习路径的前置步骤；原离线与全局长期记忆的边界不因三栏布局改变。

### 来源与引用（保留 G1–G3，更新 D1）

7. 来源目录只呈现当前区获准读取的资料；候选、处理中、失败、部分正文、已保存可辨认。同名文档保留集合和版本身份，未知类型／覆盖不能伪装完整；真实分页不以当前页数量冒充全区数量。
8. 添加来源保留 PDF、文本、网址、搜索发现四入口；实际正文、解析报告、变更与冲突可审阅，用户确认后才保存。失败项不能进入可选来源。导入与勾选为不同动作，不再要求用户另行“采用到课堂”才能在新对话中使用。
9. PDF 保留原件保存授权、大小／页数边界及逐页缺口报告，部分解析需明确接受；扫描／空白／失败页不计为已读。文本保留用户原文与编码检查；PDF 用受控页图及文本定位，不让浏览器执行未经校验的原件。
10. URL 抓取与搜索只外发获授权的公开地址／关键词，不自动外发学习方向、私人目标、笔记或成绩。搜索摘要仅为候选，用户选中后读取正文、审阅保存；未读取或不可保存的摘要不能成为出题或引用依据。网络、重定向、格式、超时与预算校验继续有效。
11. 左栏选择实时决定之后发起的对话、出题和 Studio 生成；每次受理采用当时确切来源版本，已受理运行不因后续勾选漂移。已出题的答案评估始终使用该题的资料和标准。改选不需要新的课堂审批、不删除来源、不自动共享或发布 NoteSync。
12. 未选来源不得经旧回答、工具结果、旧练习反馈、其他区或记忆进入新轮次的资料上下文；旧历史可在有权限时查看，不等于可再次外发。零选择与来源未加载／失败不同，不能回退全库。按 Q2，零来源可一般对话且无伪造引用，依赖资料的练习／生成给出简短操作入口，无常驻“未选来源，不引用资料”文案。
13. 对话、练习、反馈和 Studio 的资料引用由服务端核验归属、范围、原文及版本，可打开对应片段、章节／段落或 PDF 实际页及覆盖缺口。失权、清除、未知来源显示不可用，不替换成最新版或把模型 URL 当核验引用；移动端返回原卡片和焦点。

### 对话与内嵌练习

14. 中栏具有连续消息流和统一聊天输入；导师依据学习方向及当前资料讲解、追问与安排练习。按 Q3 保存已发送轮次、已发布卡片并支持重开／新建／切换对话，旧临时会话按原语义保留；发送前沿用模型目的地、预算和必要授权，失败／取消／未知结果可核对，不模拟成功。
15. 导师可在讲解中插入实际可作答的练习卡。只有后台题目、会话、活动及引用发布成功才显示可提交卡片，普通消息中的问题不冒充练习记录。按 Q4，每轮最多一题，每个对话同时一张待答卡；“稍后再做”保留恢复入口，不产生 Attempt、完成标志或 Evidence，也不阻止普通交流。
16. 卡片内有答案、实际帮助等级与提交；帮助等级受本题允许范围约束，已提供的提示／支架／答案展示构成服务端不可降低的下限，用户仍可申报实际使用的其他帮助。答案已展示不能按独立完成计分；聊天、IME 确认、Enter／换行及切标签不能误提交卡片。
17. 用户点击提交后才形成既有教学领域的 Attempt，绑定本题活动、内容版本、实际帮助及操作身份。聊天或笔记不会自动成为答案；重复请求、双标签竞争与响应丢失不能重复作答或覆盖另一张卡片，结果未明时先核对原操作。
18. 提交后自动进入既有评估流程，反馈以对话中的卡片出现，显示实际结论、依据、帮助状态和必要的待处理说明。评估失败可对同一答案重试，待复核／证据不足不能被模型口头肯定或“继续”按钮变成通过；需要复核时沿原授权决策路径。确认读完反馈与确认评估是不同动作。
19. 练习记录、进度、评估与到期复习读自同一后台事实；只有有效 accepted Evidence 按既有规则影响掌握与复习。聊天、阅读、生成、跳过、手动完成不增加掌握度；路线完成与掌握分开，宽泛方向不显示没有真实分母的“完成百分比”。旧方向及旧题记录仍可查，不自动转移证据。

### Studio（保留 G4–G6，取消手工目标门槛）

20. Studio 保留学习指南、测验、简报、笔记及已保存列表，支持打开指定版本和返回。类型、标题、生成状态和资料出处来自真实服务端；排队、生成、部分、失败、完成按真实状态展示，不使用定时器伪装完成。
21. 学习指南组织所选资料的核心概念、顺序、重点与常见误区；简报呈现主要结论、来源差异及覆盖缺口。资料支持与生成建议可辨认，保留核验引用和历史结果，不以旧研究综合或旧课堂阅读内容冒充新生成。
22. Studio 测验由系统按方向绑定后台目标，用户无需选目标。保留方案 A 的逐题会话、独立答案与帮助、评估、回执和进度读回；生成时的题目与资料版本不被后续方向／选择变化重写。同一题不重复计分，不覆盖对话练习、旧课堂或其草稿，界面采用“开始练习／提交／反馈”等用语。
23. 笔记可手工创建、编辑、明确保存、重开；保存前仅为标签页草稿，保存后为区内受保护的版本化产物。保存失败或冲突保留输入；复制导师内容仍需审阅保存，不自动成为长期记忆、成绩或外部权威来源。
24. 笔记转来源指定已保存版本，审阅后产生独立文本副本及版本出处；核对原操作不重复导入。修改笔记不改写副本，副本依当前来源选择进入之后对话／生成，不自动成为有效学习证据。
25. 重新生成形成新结果／版本，不覆盖原题答案、旧引用或历史产物。取消、超时、预算用尽、服务重启、响应丢失可恢复实际状态；不因刷新而重新创建运行、练习会话或生成任务。

### 配对、安全与兼容

26. 新增“学习端全权”供操作者明确签发，一次配对支持导入、参考管理、研究／搜索、学习对话、练习／评估、Studio、长期记忆候选与审阅。沿用各业务确认，不给模型自动批准候选或评估的权力；旧档案及旧设备不自动扩大权限。按 Q5，模型／搜索配置写入仍需独立 settings 权限；管理后台认证、隐私清除 grant 始终独立，新档案不能自授、进入管理后台或绕过清除授权。
27. 各端点继续核验设备 scope、Cookie、CSRF、精确 Origin、区／集合归属、服务能力和隐私代次；前端禁用不替代服务端校验。来源正文、学习方向和模型输出均为数据，不是授权；安全 Markdown、受控 PDF、不自动加载外部图片等边界保留。
28. 未发送提示词、未提交答案、导入和笔记草稿仅存在当前标签页内存，切面板／路由可恢复，刷新前提示丢失；不写浏览器持久存储或 Service Worker 缓存。缓存／请求／订阅按 origin、principal、generation、区、对话、活动／产物版本隔离；退出、失效、撤权、清除后隐藏受保护正文并阻止迟到响应复活。新方向、卡片、映射、评估任务与派生关系纳入各 owner 的清除、验证和轮换；明确保存的服务端内容与既有授权离线库遵循各自合同。
29. 所有写入保留操作身份、内容绑定幂等和 expected version；同操作同载荷返回原结果，不同载荷冲突。重启、版本冲突、失效批准与未知结果有恢复路径；模型输出不直接写入教学事实，不能通过客户端重新编号、吞错、伪成功或降低校验绕过门禁。
30. 手机底部为“来源／对话／Studio”，默认对话，切换保留草稿且不重复订阅；软键盘、长内容、安全区不遮挡提交或造成整页横溢出。菜单、标签、练习、引用、对话框可键盘操作并恢复焦点，保留状态播报、主题、对比度和隐藏面板不可聚焦。新流程有真实后端浏览器验收，旧安全／幂等／隐私／评估断言迁移保留；候选覆盖资产／深链接、适用三引擎和 CLI 兼容，未执行或跳过不得记为通过。
