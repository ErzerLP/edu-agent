# Capability：智能搜集资料

状态：Shape 文档定稿（2026-10-20），未实施。结果见 [brief](brief.md)，实现边界见[设计](../../../design/source-research.md)。依赖 [导师联网搜索合同](../mentor-web-search/spec.md)。

## 合同与验收

1. “添加来源 → 智能搜集”接受自然语言需求并直接开始，替换旧关键词发现入口及接口；不增加计划确认步骤，不把任务送到导师聊天中。
2. 开始前就地说明外发与保存范围；仅使用用户在本任务提交的需求、公开网页和已有搜集结果，不自动读取本区聊天、私人来源、学习记录或长期记忆。主动开始搜集独立于导师对话的联网开关。
3. 系统生成多个相关检索方向，按已读证据和缺口迭代搜索、读取及筛选；计划是可见进度，不是等待批准的草稿。无须凑满方向或页数才可完成。
4. 进度显示实际搜索词、正在读取及已读的页面、失败原因、已筛选候选数和当前阶段；不展示隐藏推理，不用计时器或伪百分比冒充进度。刷新或重开可恢复已提交进度。
5. 未读正文的搜索结果只能作为待读线索；不能作为合格候选或报告的事实依据。未找到可用正文时交付空清单与缺口说明，不假造资料或引用。
6. 去重覆盖同一任务各轮、规范化地址、跳转后地址和正文指纹；镜像或转载不算独立佐证。已导入来源及用户取消项不因补充搜集被重复导入或重新勾选。
7. 筛选依据需求匹配、原始或权威出处、时效、可读性与内容独立性；每项展示具体入选理由和已知缺口，优先少而相关，不为填满数量收录低质资料。
8. 网页设置提供每轮资料上限（默认 10，范围 1–20）及阅读上限（默认 30，范围 1–100），资料上限不大于阅读上限。参数不是累计预算，不能绕开单次资源限制。
9. 每轮最多尝试读取设定数量的不同 URL，失败占名额，重定向不多占名额；已存片段的重复读取不另算网页。一个 PDF 算一个网页，物理页另行展示。当前轮开始时冻结规模，设置变化在下轮生效。
10. 每轮最多推荐设定数量的新增外部资料，可另存一份报告；不足时说明原因。“再找一些”获得新一轮的相同规模范围，不受跨轮累计资料或用量预算限制。
11. 正常完成的结果包含候选清单及带引用的整理报告，二者分区展示；报告说明覆盖范围、结论和缺口，事实只引用本任务实际读取的正文，推断与示例可辨认。
12. 新候选默认全选，用户能逐条取消；报告作为单独选项默认不选，可仅选报告。多标签或刷新不得悄悄覆盖已经保存的选择。
13. 支持现有文本层 PDF 抓取、解析、页码与缺口展示；不另建解析器，不把提取文本成功等同于图表理解。部分 PDF 可入选，但导入必须另有明确接受可用文本的选择。
14. 用户确认具体结果和选择后才导入；服务端核验真实快照、版本、权限与存储许可。未选资料不写入正式来源，不自动采用目标参考、勾选问答资料或改变学习记录。
15. 报告可导入为一份明确标为 AI 整理的来源，保存确切版本及最小引用证据；未选网页不会因此变成独立来源。清除搜集任务后，正式报告仍能核对已保存的引文及地址，不能凭报告引用重新读取被清除的全文。
16. 导入逐项有稳定回执；重试或响应丢失不重复创建来源，成功项不因另一项失败回滚或重做。跨轮同一快照复用已有导入，网页变更不自动覆盖原版本，报告新版本不覆盖旧版。
17. 用户随时可停止；停止确认后取消在途请求并禁止后续模型、搜索、抓取和报告生成。已经提交的候选、报告部分和用量保留，未提交的迟到正文不能进入结果。
18. 停止或失败后可查看并导入已经校验的候选及可用报告部分，清楚标记未完成；没有报告正文就不可导入报告，不为补齐结果在停止后自动调用模型。
19. “继续”恢复同一轮未完成工作，不重读已完成页面、不重做已提交报告部分；重新核验权限及目的地。对外发结果未知的步骤不自动重发，用户继续才可重试，真实新请求另计数。
20. “再找一些”仅在当前轮非活动时开启补充轮，保留需求、去重与用户选择，允许补充一句需求；展示本轮新增结果和更新后的报告，旧报告版本仍可查。它不等同于恢复同一轮。
21. 同一任务最多一个活动轮；重复开始、停止、继续、补充及导入由操作标识和版本处理，冲突先刷新；读取状态、重连事件和服务重启不创建新任务或重复副作用。
22. 到达阅读上限、方向已覆盖或无新增可读线索时结束检索并说明缺口；单页失败可跳过，提供商整体不可用或模型失败保留进度并说明原因，不无限重试。
23. 所有规划、筛选、上下文整理、报告分段、修复及汇总模型调用归入同一搜集任务的现有用量台账；搜索实际请求分别计数，网页读取单独展示。无累计预算，未知用量不得填零。
24. 搜集 agent 的搜索／读取工具同样尊重用户设定的 `Limits.MaxToolSteps`，默认不限；达到工具上限则说明进展，继续后重新计数但不重置本轮阅读名额。报告分段受单次输出与窗口限制，不能把所有正文一次塞入模型。
25. 复用安全抓取和不可信内容隔离；网页、搜索摘要或报告不能授予工具、知识写入或跨区权限。模型无导入工具，导入只能由用户操作触发。
26. 查询、计划、进度、选择、正文、PDF 和报告均属于当前学习区的搜集任务，受加密、保留周期、删除及隐私代次管理；全局清除覆盖任务与正式来源，旧租约或旧链接不能恢复数据。
27. #22 目标研究与新搜集工作流并存，共用底层能力；新搜集不沿用四候选限制或自动采纳。移除旧关键词发现接口及其预算字段，不新增旧接口别名或历史数据转换，CLI 不在本 change 范围。
28. 进度、停止、选择、报告查看、导入及补充操作可用键盘和移动端完成；运行不阻塞正常学习，错误和部分完成可被辅助技术读取，新增 API 通过部署路径检查。
