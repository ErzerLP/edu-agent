# Shape：Studio 规划、分段生成与对话整理

状态：Shape 待审（2026-10-18）。依据 [#118 正文及确认评论](https://github.com/ErzerLP/edu-agent/issues/118)，依赖 [用量统计](../model-usage/brief.md)和 [#117 话题索引](../conversation-topics/brief.md)。

## 结果

用户先在 Studio 面板查看和修改生成规划，确认后看内容逐段完成；停止后可以从已保存进度继续。内容围绕学习方向和薄弱点展开，事实来自所选资料。用户也可在对话中选几个话题，整理成笔记或复习测验。

## 范围

- 学习指南、简报、笔记先生成大纲，规划各部分与资料章节；在 Studio 面板下方通过输入框修改，也能删除和拖动排序。
- 生成依据为所选来源、学习方向、跨本区学习记录提炼的有界学习状态摘要，以及可选侧重点；提供侧重点建议标签，不读原始对话。
- 确认后逐段读取相关片段、生成、校验引用和保存，展示真实进度，支持停止和继续；最后一次简短调用补总览、衔接和未覆盖范围。
- 测验使用题数、知识点、题型、难度的轻量题目规划；确认后生成题目，沿用每题独立作答、提交和反馈。
- 对话中的“整理本次对话”仅生成笔记或复习测验，可勾选话题；来源仍是唯一事实依据。

## 非目标

- 不读全区原始聊天作为 Studio 输入，不用聊天热度、摘要或生成内容增加掌握度。
- 不新增整本书导入、向量检索、多媒体产物、协作编辑或后台自动无限生成。
- 不修改既有答案、成绩或历史产物；不改 CLI 的交互，不让用户再填 Token 预算。

## 关键决定

| 决定 | 行为 |
| --- | --- |
| 修改留在 Studio | 大纲输入不发送到中间导师对话，不创建练习或改变学习记录。已确认后才开始内容生成。 |
| 两种摘要用途分开 | 学习状态来自学习记录，用于建议重点；对话话题只界定本次整理范围。二者都不能成为资料引用。 |
| 一段一保存 | 当前部分通过引用校验才进入完成数；失败不删除此前成功部分。 |
| 继续沿原规划 | 来源版本、方向、规划和选定话题在受理时确定；继续不会悄悄跟随最新选择。修改已确认规划需重新确认。 |
| 测验沿既有学习路径 | 生成题目不代表完成练习；用户开始和提交后才进入作答与评估。 |

协议、状态、migration 和分批计划见[设计](../../../design/studio-staged-generation.md)，完整可观察行为见 [spec](spec.md)。

## 端到端验收示例

- 用户选择网络教材，看到“上次答错的子网划分”等建议标签。生成指南大纲后在 Studio 输入“先讲子网，删掉最后一节”，再拖动顺序，确认后逐段生成；每段引用只指向所选教材。
- 已完成 3/8 时停止，刷新后仍可看这三部分并继续；第 4 部分引用无效时不计入完成，重试只处理尚未成功部分。最后汇总失败也保留已完成内容。
- 在长对话中选中 TCP 和子网两个话题整理成复习测验，先确认题目规划，再开始练习。另一个对话中的错误记录可影响建议重点，但不会把那段聊天内容或未选资料发给模型。

## 仍需用户决定

- **S1：是否保存已经发送的大纲修改对话？** 建议随生成任务保存，刷新或重开后可查看；未发送文字只留当前标签页内存，删除任务／隐私清除时一并清除。
- **S2：首版题目规划开放哪些题型？** 建议先沿用可文字作答的开放题，区分简答／解释题，难度可选；默认 3 题、支持既有 1–8 题。选择题、自动判分等新题型另做 Shape，避免顺带改变评估规则。
- **S3：停止后的部分结果能否直接作为产物使用或开始测验？** 建议首版可查看已完成部分，但完成全部规划和汇总后才进入已保存产物并开放测验；停止可继续，失败只重试未完成部分。若希望直接保存部分笔记或练习部分题目，需要增加“结束并采用部分结果”的明确动作与覆盖说明。
