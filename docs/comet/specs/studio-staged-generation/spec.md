# Capability：Studio 规划、分段生成与对话整理

状态：Shape 已确认（2026-10-18），未表示已实施。见 [brief](brief.md) 与[设计](../../../design/studio-staged-generation.md)。

## 合同与验收

1. 常规 Studio 生成仅使用所选来源、学习方向、有界学习状态摘要和可选侧重点；不读取原始对话。所选来源是内容事实的唯一依据，引用只能指向实际使用的所选片段。
2. 学习状态摘要从同一学习区所有获授权的学习记录提炼，包含近期所学、错误或需要帮助的练习、已有掌握证据；不把聊天自述、跳过、未评估答案或阅读当成掌握。
3. 用户可填写侧重点或点击根据学习状态生成的建议标签；没有记录时不伪造薄弱点，记录不足不阻止基于来源生成。
4. 学习指南、简报、笔记先产生包含部分主题和资料章节的大纲；来源不足或尚未覆盖的范围可辨认，不能宣称读完未读取的内容。
5. 大纲在 Studio 面板展开，下方可用输入框多轮修改；也支持删除和拖动排序。修改不发到导师对话，不产生作答或评估。
6. 只有用户确认当前规划后才开始生成内容；修改后的规划需重新确认，旧确认不能套用到新修订。
7. 已经发送的大纲修改对话及其结果随生成任务保存，刷新或重开后仍可查看；未发送草稿只留标签页内存，失败保留输入且不伪装修改成功。删除任务或隐私清除时一并清除。
8. 测验先展示题数、每题知识点、题型和可选难度的轻量题目规划，可通过对话修改并确认；首版只支持文字作答的开放题，分简答和解释两类，默认 3 题、允许 1–8 题；选择题、自动判分以后另做 Shape。
9. 生成按规划逐部分进行，每次只发送相关且有界的来源片段；目录和单章很大时也不能把全部正文一次塞入请求，所有调用遵守单次输出及窗口限制。
10. 来源总量超过单次窗口时仍可按确认规划完成生成，未纳入和未覆盖范围明确展示；不因累计来源体积直接失败，也不假装已覆盖全部所选资料。
11. 每个部分生成后立即核验引用并保存，通过校验才计入完成数；引用无效的部分不能以“已完成”展示或进入产物。
12. 用户看到真实完成数、当前阶段和失败位置；刷新、重开与服务重启可恢复已保存进度，不靠客户端定时器模拟生成。
13. 用户可以停止生成，停止后不再派发后续调用；已完成部分保留，当前调用的未知结果和已发生用量可区分。
14. 用户可以继续原任务，只处理尚未完成部分；继续仍核验权限、资料与目的地，不重复生成或覆盖已成功部分。
15. 最后一次简短调用生成总览、衔接和未覆盖范围；它不能引入新的事实来源。汇总失败时保留所有完成部分，只需重试汇总。
16. 停止后可查看已完成部分，并从已保存进度继续；只有全部规划内容及汇总完成后才发布产物版本并开放测验，部分结果不冒充完整结果。
17. 指南、简报及生成笔记保持各自用途；生成笔记可在完成后按既有笔记方式编辑、另存版本和转来源，来源引用不能因手工编辑失效而继续冒充已核验。
18. 测验继续沿用每题独立会话、答案、帮助等级和评估；生成或开始题目不产生已掌握结论，重复开始／提交不能重复计分。
19. 重新生成产生新结果／版本，不覆盖旧产物、旧题答案、旧来源引用及其学习记录；既有产物与每题会话仍可按原版本访问。
20. 对话中提供“整理本次对话”，只生成笔记或复习测验，可选择全部可用话题或部分话题；受理范围与所见话题版本一致，未选择话题不能混入。
21. 整理入口通过 #117 的话题投影表达关注内容，不直接读取原始对话；话题未覆盖最新内容时明确提示，可先整理话题再生成，不冒充已完整覆盖。
22. 整理产物仍需所选来源支持事实与引用；无可用来源时引导选择资料，不把对话、话题摘要或其他对话的来源当成事实依据。
23. 已受理任务使用确定的来源版本、方向、学习状态和规划；用户后续改变勾选或方向不重写在途任务。来源撤权／清除后停止相关内容读取与生成，不替换成别的资料继续。
24. 所有规划、修改、分段、修复及汇总调用进入同一次生成的用量明细；不再要求 Token 或请求次数预算，停止与未知用量遵从 U 合同。Studio 分段生成的步数由确认后的大纲决定，不受“每轮工具调用上限”影响。
25. 多标签修改、重复确认、重复继续和响应丢失通过版本冲突及原操作核对处理，不创建重复任务、重复产物版本或重复测验会话。
26. 新任务、规划修改、状态摘要、话题范围、分段与产物均纳入原权限及隐私清除；旧代次迟到响应不能恢复数据，界面不显示后台身份与协议术语。
27. 旧产物、旧笔记和旧 API 请求保留设计中明确的兼容路径；旧预算字段不再限制执行，不要求 CLI 更新才能继续使用既有功能。旧固定结构生成入口不获得新的动态大纲能力。
28. Studio 大纲、排序、确认、停止和继续可用键盘操作；移动端修改大纲时能保留草稿和引用返回位置，错误说明与进度可被辅助技术读取。
