## 开发方案（实施前）

拆分评估：选段加工、独立库可以分别演示，但共享内容版本、来源权限和公开协议，
在当前专用工作树串行完成三个有界批次，不并行修改共享 schema/OpenAPI。

1. **局部内容命令**：UTF-8 字节范围及 SHA-256 绑定区/目标/教学会话/artifact/version/block。
   请求和发布均核对定位，版本比较与操作幂等在同一 PG 事务完成。原题/评分块只允许附加解释；
   可编辑的派生块允许精确替换。版本加密保存基线、触发原因、修改块、模型与来源链。
   恢复生成新的补偿修订，固定版本只改变阅读偏好。
   退出：领域回归和真实 PG 覆盖局部性、冲突、恢复、幂等及原活动不变。
2. **模型与工作区闭环**：扩展现有导师运行，服务端读取准确选区上下文，校验完整候选后原子提交正文与运行结果。
   流式输出是草稿，取消/错误/预算暂停保留可读部分；发起、恢复和提交都检查原身份与权限。
   Web 提供鼠标选段、键盘替代、可移除 chip 和动作，输入在失败/过期后保留，更新保留答案和阅读位置。
   退出：模型 fixture 到指定块正式版本、停止/迟到/清除回归及 Web 类型/单测。
3. **Studio、来源与交付**：内容自动按目标列出，类型/知识点/来源/收藏/时间筛选和分页，独立阅读、差异、导出、固定/恢复。
   引用按正规 knowledge 范围重新验证，返回具体片段、上下文、版本和真实解析缺口；派生内容保留原始链。
   同步 OpenAPI、代理、隐私清除和中文使用文档；运行受影响包、PG、构建与浏览器链路。
   退出：真实记录驱动的完整 Web 场景及逐项验收记录。真实模型样本单列，不把 fixture 当真实模型效果。

## 验收标准（实施前）

- 从真实教学内容选段，模型收到明确身份、原版本与选区；完整合法候选才成为正式新版本。
- 附加解释/例子直接执行，未选块不变；原题、interaction、rubric、目标与既有证据不被偷偷改写。
- 过期选区、错误 hash、跨区、并发版本冲突明确失败；保留用户指令，操作重放不重复提交。
- 流式半成品、取消、超时、预算不足不产生正式内容版本，原版和真实部分输出可读。
- 当前答案和阅读锚点保持；切区、换活动及迟到观察结果不污染其他上下文。
- 来源解析核对真实修订、片段和范围，未知引用/越权被拒绝；缺口明确展示。
- Studio 无需收藏即自动收录，筛选/分页/独立阅读/Markdown 与结构化导出使用真实数据。
- 固定旧版、查看差异、补偿恢复可操作；恢复不声称撤销学习或迁移评分。
- 派生版本只继承原始来源链，不把自身副本注册为外部权威；引用到任务需要明确选择目标任务。
- 隐私清除及来源权限失效后，历史、运行恢复、索引与客户端缓存不能复活受限正文。
- IME、键盘选择、弹层焦点、窄屏及深浅主题可用。
- OpenAPI、权限、真实 PG 版本/幂等、模型 fixture 与浏览器链路分别记录实际结果；未运行项不写为通过。

不实现教学路径变更、替换已发行题目、多人富文本协同或任意插件。交付仅提交当前任务分支，
遵守专用工作树明确的“不合并、不变基、不推送基础分支”约束。
