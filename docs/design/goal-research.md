# 目标研究与可追溯来源（Issue #22）

## 缺失确认

起点 `549c4fe`，工作树干净。`server/internal/settings/service.go:230` 将研究能力固定为 `not_implemented`；`server/internal/mentorrun/core.go:48` 的工具只有读取目标、问询和交流确认，`:61` 明确没有研究能力；`clients/web/src/components/goal-composer.tsx:244` 仍显示未接入。`server/internal/integrations/websearch/client.go` 已有供应商无关搜索接口和 Brave 实现，但调用者仅为设置连接测试，没有正文抓取、来源修订、采纳命令或研究页面。不是已有功能的别名或隐藏设置。

## 架构与实施方案

模块化 Go 服务、PostgreSQL 权威存储、同源 React 客户端。identity 负责凭据和 scope，learning 管理目标与运行，knowledge 管理正式资料，settings 管理外部连接和预算。CLI、教学、掌握度不在本次修改范围。

保持单一垂直结果：从无资料目标发起研究，查看真实片段和缺口，在明确授权内采纳。串行修改公共协议和组合入口，避免独立建设第二套运行或知识库。

1. 新增 research 领域：公开主题、补充/优先/限制域政策、候选和来源修订、片段、综合要点和缺口。专用 client 固定安全 scheme/端口、每跳公共 DNS 与实际拨号地址，限制跳数、超时、原始/解压大小；解析不执行脚本，不支持的格式准确失败。
2. 扩展现有持久运行为研究执行：检查明确同意和请求预算；只把用户确认的公开主题交给搜索和综合模型，不加载私人目标/成绩/资料；持久阶段、候选和实际读取计数。沿用操作回执、租约、取消、未知在途结果、加密 checkpoint 与清除。
3. 正式采纳调用 knowledge 的受限新增命令，与运行授权/隐私/版本核对和回执在同一事务；使用新身份及独立目标参考，禁止覆盖、共享和同步发布。候选缓存不作为可检索正式知识；综合结论与外部原文分别标识。
4. HTTP/OpenAPI 增加研究、分页来源列表/详情和采纳决策；先验证区、目标、设备再检索和分页。React 独立研究页显示真实数量、阶段、停止、重试、片段和上下文，无已知分母不显示百分比。

## 验收标准

- 无资料目标经过真实搜索 HTTP 适配、正文 HTTP 解析、模型综合、持久结果和浏览器展示。
- 搜索摘要不作为正文；候选、失败、部分解析和已采用分开；每条支持引用必须匹配实际来源修订、片段及原文。
- 私人目标和成绩不自动外发；政策在搜索请求和每跳抓取前生效；恶意内容没有工具或权限入口。
- 拒绝非 HTTP(S)、非标准端口、私网/loopback/link-local/元数据、IPv6 转换绕过、混合 DNS、重绑定、危险重定向、压缩炸弹和超限。
- 自动采纳必须有明确目标内授权、knowledge 权限和有效运行；新文档经 knowledge 正规写入和审计，不覆盖既有身份或产生跨区共享/同步。
- 同操作恢复、重启、预算暂停、停止和部分结果符合 #21；跨区及伪造来源不可读取/采纳。
- 全局清除和运行清除移除候选正文、综合输出和来源关系；正式知识遵循 knowledge 清除，不可通过旧 checkpoint 恢复。
- 受影响 Go 测试、真实 PostgreSQL 隔离 schema、定向 race/vet、OpenAPI 和前端类型/单测/构建；浏览器与真实外部提供商 smoke 分别记录，未运行不得算通过。

本任务遵循专用工作树的明确边界，保留当前分支供审查，不合并或推送基础分支。

## 实施细节与边界

- 研究会话与导师会话按 `kind` 分离，仍共享原运行表、回执、配额和 worker；追加 `000022`，不修改历史迁移。
- 候选保存在有界运行 checkpoint，只有明确采纳的来源进入 `knowledge_source_revisions`；后者仅保存范围、版本、元数据和正式知识正文定位。运行到期/清除后仍可查看获准保留的历史来源；全局隐私清除同时清理两个 owner。
- 来源集合固定为新建、私有、目标关联，不使用默认同步集合，不提供覆盖或身份合并字段。`research` 配对档案显式保留 `knowledge:read/write` 与 `research:adopt`，旧浏览器身份不升级；服务端在每次采纳前重新核对真实凭据。
- 每次研究最多四个候选，最多四次重定向，每个页面原始 1 MiB、解压后 2 MiB、解析文本 16000 字节、25 秒。标准 80/443 端口、每次连接全部 DNS 地址检查和数字地址拨号；没有来源端点允许列表或环境代理绕过。
- 支持公开 HTML 文本、Markdown 和 UTF-8 文本；HTML 仅提取静态文本，始终明确标记部分覆盖。PDF、其他编码、不可读正文及禁止保存/索引的响应分别报告。
- 模型仅核对各来源前三个片段；省略范围在页面可见。综合、原文和自拟例子分开，综合不写入可检索知识。引用验证限制于实际发送给模型的片段。
- 运行“清除”不撤销此前明确的正式采纳；界面对此单独说明。全局隐私清除覆盖候选、综合、正式正文、索引及来源关系。
