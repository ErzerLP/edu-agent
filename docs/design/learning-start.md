# 空资料开学与动态知识上下文（Issue #24）

## 缺失确认

基线 `a288e76`，工作树初始干净，已包含 #22、#23。
`clients/web/src/components/goal-composer.tsx:242` 仅允许已保存目标跳转会话，新目标的开始按钮禁用。
`server/internal/learning/planning.go:392` 正式应用必须经过引用校验；`:312` 的
`validatePlanningReferences` 拒绝空来源中的步骤。执行
`go test ./internal/learning -run '^TestPlanningRejectsInvalidPrerequisites$' -count=1 -v`
通过，实际断言正是“无引用大纲不可执行”。研究在
`server/internal/mentorrun/research.go:207` 采纳来源后结束，没有教学应用步骤。
仓库没有 KnowledgePolicy、KnowledgeContextRevision 或稳定概念身份。
因此是生产链路缺失，不能通过已有设置开启；必须保留引用校验。

## 架构与实施方案

服务是 Go 模块化单体，PostgreSQL 保存权威事实，React 提供同源学习入口，CLI 保留严格旧协议。
knowledge 拥有来源、概念和知识上下文，learning/tutoring 拥有活动、事件和教学现场，
learningcontent 拥有正文版本，mentorrun 拥有授权、预算、租约、加密检查点与恢复。

本项只有“输入目标后在空资料库开始首项活动”一个主要结果，跨 owner 提交必须一致。
共享迁移、组合根和协议串行修改，复用现有研究 worker，不再建立另一套任务调度。

1. 为目标内开学增加独立运行类别，复用研究的真实搜索、正文和采纳；明确授权公开主题、
   模型输入、自动采纳和预算。保存目标入口仍只保存。已有教学会话由用户明确选择，
   新开学显式创建独立现场，不依赖全局 current。
2. knowledge 分离政策与实际上下文版本；稳定概念以目标内语义键标识，修订关联真实来源片段。
   用自动冻结的兼容资料快照连接旧教学引用，用户无需创建集合或冻结资料。
   新知识只推进 context，目标文本、范围和完成标准不变。
3. 研究完成后用已知目标信息准备一项有来源支持的简短讲解加开放题/实践活动，无需长诊断或完整课程。
   外部模型调用在事务外；正式路线、活动、内容和回执通过原应用服务及同事务窄接口发布。
   发布前再次检查设备、区、目标版本、隐私代次、运行租约及停止状态。
4. 会话和活动保存可空 context、artifact 版本关联，新查询呈现概念与支持状态。
   旧记录保持原 ID/事件，旧 API 继续提供原字段及 `open` 活动兼容投影。
5. 首页接通保存并开始，研究页显示真实进度并自动进入课堂；失败保留目标和研究结果，
   可追加预算或显式重试。新增能力、OpenAPI、Web DTO 与隐私清除同步交付。

## 验收标准

- 空库、无上传：Go、英语、数学三个不同模型夹具通过搜索/读取/采纳后生成正式首活动及正文。
- 无需手工建集合、冻结范围、重输目标或生成完整课程；仅保存不创建运行或教学会话。
- 模型输入复用已填基础、用途、约束；允许不确定先开始，不擅改目标或生成掌握度证据。
- 每个概念和活动可定位到正式来源修订与支持片段，AI 文本不作为外部原文。
- 相同政策推进上下文而不改目标；旧会话、活动、题目/rubric 及正文保持原版本。
- 同操作、刷新、重启恢复同一运行/现场/活动；不同目标、区和并发请求互不串线。
- 搜索、模型、来源不足和预算失败真实呈现；暂停、归档、撤销、停止、清除后迟到结果不能发布。
- 真实 PostgreSQL 验证 context、概念、活动、artifact 和运行回执一致提交及故障回滚。
- 旧 CLI 严格 DTO 可读取兼容投影；新接口能力、协议和运行时 DTO 一致。
- 受影响 Go 测试、定向 race/vet、真实 PG、Web 类型/单测/构建和浏览器场景分别记录。
  真实模型加搜索 smoke 如缺少已授权配置，则单列未运行，不冒充夹具验收。
