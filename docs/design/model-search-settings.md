# 模型、搜索与能力配置（Issue #20）

## 缺失确认

核查提交 `44a5121`（已含 #18），工作区初始干净。`clients/web/src/pages.tsx:647` 的设置页只有身份、静态能力和数据说明，没有模型/搜索表单；`server/internal/transport/httpapi/api.go:303` 仅挂载旧 `GET /v1/model/capabilities`；`server/internal/platform/config/config.go:64` 仅有一份环境变量教学模型对象。旧探测直接执行 `a.model.Probe`（`api.go:695`），不是只读能力发现。全仓没有服务端 Web 导师、搜索适配器或预算设置入口。因此工单所需的独立配置与能力发现确实缺失；已有 CLI 凭据、NoteSync 管理设置和目标保存不属于缺陷。

架构已核对：Go app 组合 identity、learning/tutoring、knowledge、memory/privacy、HTTP/MCP；PostgreSQL 保存学习与身份状态；React 学习端调用同源正式 API，CLI 是独立客户端。复用浏览器会话实时认证、Origin/CSRF、旧学习业务和 OpenAPI 类型生成。

## 开发方案（实施前）

保持一个垂直用户结果，串行修改共享接口与应用组合，不引入研究运行或聊天历史。新增独立 settings owner，配置和 Key 原子保存到服务端专用 0700 目录中的 0600 文件，文件版本及配置 revision 用于恢复和并发冲突。公开 DTO 与秘密记录分离，API 只接受替换值或显式清除，换供应商/端点清除旧凭据。文件路径与端点允许列表仅由服务器操作者设置。

1. 三个槽位：教学、Web 导师、搜索。导师可显式引用教学配置，独立配置保留且不被覆盖。旧教学环境配置只作为未被显式设置覆盖时的只读起点；不访问 CLI 配置。已有教学执行在服务重启后应用，API/UI 明确显示待重启，新的配置与探测立即可用。
2. 普通学习身份读取非敏感设置/能力；新增 `settings:write`、`settings:probe` 仅由显式 `settings` 配对档案授予，旧 user/agent 档案和旧设备不升级。新的写/探测入口要求浏览器学习身份和 Origin/CSRF，admin Cookie 不具有此身份。
3. OpenAI-compatible 模型适配器支持显式许可的本地/自托管地址及无鉴权模式；搜索定义中立接口，实现 Brave Web Search。精确模型端点允许列表与搜索网络策略分离，禁止重定向转送 Key；没有网页抓取授权的复用接口。
4. 保存/读取不探测。显式探测确认可能发出外部请求/费用，只发送固定公开样本；总时间、输出与响应大小有界。持久化类别、能力与时间，不记录外部正文/原始错误。配置变化使旧探测失效，过期成功不当作当前保证。
5. 保存研究请求/Token 预算、输出/上下文、无响应超时、并发、存储上限和外发策略；未知费用不产生金额。后续运行接受/续行必须重新执行预算与隐私策略；不引入固定教学轮数或把 SSE 存活期设为整次超时。
6. 新增无外部请求的能力合同，区分未实现、未启用、缺配置、未探测/过期、探测失败，包含 schema、渲染、作答、搜索、持久化。研究/Web 导师执行继续明确未实现；保留旧能力入口和会话字段。
7. 设置页按显示、教学授权、模型与搜索、会话数据、设备组织；显示配置状态、发送位置、探测时间与原因、预算、用量说明、安全替换/清除入口。Key 仅存在输入期间，提交即清空，不进入查询缓存、浏览器 storage 或地址。

## 验收标准（实施前）

- 真实 HTTP 保存、读取、重新打开秘密存储恢复，revision 冲突不覆盖；公开 JSON、日志、错误与前端存储不出现测试秘密。
- 普通设备读成功，写/探测失败；显式 settings 档案可操作；无 Origin/CSRF、admin Cookie、撤销及收回 scope 立即拒绝。
- 教学/导师独立与显式复用、换端点清 Key、替换/清除/重启应用分别验证；CLI 不变。
- 未配置、禁用、非法格式、401、连接失败、超时、无效响应及未实现可区分；失败探测带时间，保存/能力查询不发外部请求。
- 模型和 Brave 通过确定性 HTTP 连接测试，验证固定公开请求、凭据头、输出/响应界限、拒绝重定向；真实提供商 smoke 单列，无凭据不计通过。
- 本地模型仅精确允许地址可连接；搜索公共网络校验不接受模型允许列表；端点 URL 不含凭据、查询或片段。
- 所有限额有类型、范围、默认值及关系测试，外部查询默认禁止私人目标/正文/成绩；未知估价不伪造金额。
- API/OpenAPI/前端运行时 schema 一致，旧模型能力及会话入口兼容；无配置仍可保存目标。
- 运行受影响 Go 测试/race/vet、OpenAPI 合同、前端类型/测试/构建和可用的真实数据库/浏览器检查；缺依赖明确记录。
- 文档覆盖权限授予、生命周期、备份/轮换/清除和网络策略。按本次专用工作树任务边界交付审核，不合并或推送基础分支。
