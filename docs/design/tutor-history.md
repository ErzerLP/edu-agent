# Web 导师历史与临时对话（Issue #33）

## 缺失确认与架构

基线 `a5bf595`，工作树干净。已阅读项目开发规范、导师运行设计、模型配置、
课堂教学及内容/变更接入路径。模块化 Go 服务以 PostgreSQL 为权威，React 通过
设备身份、scope、CSRF 与隐私代次访问；CLI 本地历史是独立合同。

现有 `server/internal/mentorrun/store.go:409` 通过区/目标/设备/代次/kind 唯一约束
只允许一个 runtime session；`:423–424` 每次建立七日运行且仅放入当前 prompt，
没有读取前轮消息。`server/internal/transport/httpapi/mentor_runs.go:30–43` 仅提供
运行/当前运行及命令，无会话 CRUD；`clients/web/src/main.tsx:190–206` 无 chat 路由。
因此 #21 的恢复只恢复一次运行，不是永久聊天历史，设置无法开启本项能力。

## 开发方案（实施前）

保持一个垂直能力，依次完成存储/运行、HTTP/Web、验收；不并行修改公共 schema。

1. 追加 TutorConversation 与 TutorTurn 迁移。独立标记新历史会话，旧运行不迁移。
   绑定设备、区、可选目标/课堂与 privacy generation；运行仍由现有 worker 负责。
   正式提交轮次按 run 去重，与 checkpoint 同事务提交；永久历史无七日自动淘汰，
   临时 checkpoint 仍遵循七日上限。列表按最近活动分页，标题加密、查询有界。
2. 新轮只读取已提交消息，保留完整工具组及来源引用，不恢复执行旧工具/批准。
   恢复读取真实当前运行。跨上下文保留原绑定；同一会话的并发提交由数据库串行化。
   大历史明确达到上下文/存储上限，不偷偷丢弃记录。临时模式正文和标题不落库，
   重启返回正文不可用；已获授权的学习/内容业务事实遵循原 owner。
3. 端点确认绑定确切 provider/endpoint 及会话版本，变更后默认只读；恢复和列出
   不调用模型。首次发送明确显示自托管保存位置、外发范围与非端到端加密边界。
   沿用独立密钥；补充停机密钥轮换、备份恢复/隐私屏障和错误失败关闭。
4. 新增会话列表/详情/创建/重命名/删除/轮次接口、OpenAPI 和 Web 白名单。
   课堂侧栏、目标页及独立 `/app/spaces/:spaceId/chat/:conversationId` 复用组件、
   订阅和内存草稿。选择器默认当前上下文，支持显式其他上下文与学习区入口。
   删除需二次确认并以服务端结果为准；清除覆盖正文、标题、索引、checkpoint、
   运行残留与内存。删除对话不删除正式业务事实。

## 验收标准（实施前）

- 真实 PostgreSQL 创建多个会话、按上下文列出/搜索/分页、重命名、恢复和删除；
  两轮模型输入确实包含已提交前轮，旧运行不会自动成为历史。
- 侧栏与独立页是同一 ID、同一 run；切换不重复发送，草稿保留，窄屏可用。
- 原区/目标/课堂绑定、设备权限、代次与版本不可重标记；跨区拒绝错误 header。
- 保存轮次在重启及运行 TTL 到期后仍可读；恢复零工具/模型调用；过期交互拒绝。
- 临时正文/标题/摘要在数据库中不存在；重启明确不可恢复，不能改成保存模式。
- 新端点未确认时零外发，确切目的地确认后才允许新请求；配置再次变化重新确认。
- 错误密钥、损坏/未来 schema、配额、存储失败均明确失败，无明文或空历史兜底。
- 删除/隐私清除阻断旧 checkpoint 和迟到输出，正式学习事实不受聊天删除影响。
- 受影响 Go、HTTP/OpenAPI、迁移、真实 PG、定向 race、Web 类型/单测/构建及
  真实服务浏览器恢复场景通过；未运行项和既有失败单独记录，不冒充通过。
- CLI 本地历史、原生 Keychain 和模型凭据不迁移、不改合同。

自动标题只从本地有界首条用户文字提取，不额外发模型请求；不生成摘要或保存隐藏推理。
