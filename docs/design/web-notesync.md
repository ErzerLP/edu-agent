# 学习端 NoteSync（Issue #35）

## 问题确认与架构

基线 `e52f5ca`，工作树初始干净。`clients/web/src/api/tasks.ts:6–16` 仅注册研究、
开学、内容、导师和导入，并明确说明同步尚未接入；`main.tsx`、`knowledge-page.tsx`
没有同步页面，业务代码没有 NoteSync 请求（生成的 OpenAPI 类型已有合同）。
`deploy/web/nginx.conf:25–36` 的白名单不含 `/v1/knowledge/notesync/*`，公开学习
入口无法使用该合同。这是入口和适配缺失，并非隐藏设置。

Go HTTP 已在 `transport/httpapi/api.go:334–338` 注册五类正式接口。
`integrations/notesync/review.go` 持有预览、基线复核和解决流程；knowledge PostgreSQL
store 保存不可变审阅、操作收据、映射和发布 Outbox，已有隐私代次和解除引用校验。
采用/合并走原 knowledge Import 创建新修订；旧课堂与证据引用不覆写，后续教学引用
调整仍走 #30/#26 正式知识维护和学习变更。React/TanStack 使用独立学习 Cookie、
CSRF、设备和代次；普通 Web 身份只有读取权限，既有 import/references 授权允许解决。

## 开发方案

同一垂直结果跨 HTTP、Web 和部署，不新建同步引擎、数据库表或通用运行任务。

1. 保留五类原合同；学习请求显式携带区和集合。补齐 HTTP 默认映射/引用校验，
   状态只为学习浏览器增加安全的配置来源说明（保持旧 CLI 严格解码兼容）；增加原设备、
   原操作的只读结果核对接口，复用原收据。解决预览调用同一校验和 knowledge 计划器，
   提供真实影响与原身份审阅，不提交修订。浏览器审批使用既有 knowledge:approve，
   research:adopt 单独授权不能成为同步审批权。
2. 来源页提供同步导航；同步页显示真实配置、版本、映射和原审阅状态。任务中心注册
   NoteSync 专用适配器，列表和详情使用同一审阅 URL，不创建 research run。
3. 显式预览不发布。详情展示基线、本地、远端正文、三方差异、路径、身份和修订。
   三个原解决动作先确认；版本过期保留差异供对照，重新预览取得新审阅。
4. 未知响应停在核对状态，读取原操作和审阅，不能自动换 ID 重放。页面刷新从持久
   审阅恢复；未证实完成不显示成功。正文只留内存，查询无落盘缓存，身份变化和隐私
   清除时清掉显示；后台迟到响应不能恢复已撤销内容。
5. 未映射区/集合、解除引用、归档、权限缺失、远端故障、部分预览与过期各自提示。
   窄屏切换正文面板；连接设置指向操作者本机/SSH 安全入口，不复用 admin 会话。
6. 同批更新 OpenAPI、部署白名单、使用说明和验收记录。上游没有独立拒绝/远端删除
   合同；保留本地可能排队回发，不能把取消浏览、断连、归档和解除引用叫作删除。

## 验收标准

- 学习 Cookie/CSRF/原设备身份可读取真实状态，配置来源和固定映射清楚且没有 Key。
- 普通身份可预览但不能解决；获准身份使用原解决合同，管理会话不能替代学习身份。
- 非默认区、研究集合、跨区 ID、解除引用均拒绝；归档阻止新预览和解决。
- 预览不产生知识修订或远端写入；正式采用/保留/合并遵循原基线和幂等校验。
- 本地/远端变化使旧审阅失效；原差异可对照，新预览可导航；未知响应只核对原操作。
- 三方正文、裁剪提示、实际文档身份及影响可查看；旧教学与证据仍引用旧修订，未来
  引用变更通过正式维护入口处理，不能凭同步动作复制学习证据。
- 任务中心显示 NoteSync 原状态并跳回同一审阅；故障、缺映射和部分结果不显示为空。
- 隐私/失去身份/解除引用后清除浏览器正文，历史导航和缓存不能复活；错误只显示安全码。
- Web 单测、类型检查、构建和浏览器桌面/窄屏；Go 受影响包、OpenAPI、原 NoteSync
  fixture 与真实 PG 定向回归通过。真实 NoteSync 远端 smoke 单列，不用 fixture 替代。

安装锁定依赖和建立独立测试容器已请求用户确认；等待期间继续不依赖它们的实现。
任务上下文禁止合并/推送基础分支，交付当前任务分支供审查。
