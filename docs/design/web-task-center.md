# Web 可恢复导入与任务中心（Issue #28）

## 问题确认与架构

基线为 `fd037ca`。`clients/web/src/main.tsx:128` 注册的路由没有任务中心；
`clients/web/src` 中 import-jobs 只存在于生成的 `api/schema.d.ts`，没有请求调用。
服务端 `knowledge/import_jobs.go:108` 已实现创建、上传、预览、确认、逐批继续与对账，
`transport/httpapi/import_jobs.go:38` 已挂载真实接口，CLI 已使用这些合同。
因此缺失的是 Web 入口和运行列表查询，不能重建后端任务执行器。
另在 `server/internal/identity/web.go:32` 确认旧 Web 身份会过滤资料写入/审批，
新增显式 `import` 配对档案和 `imports:web` 标记，仅新授权设备保留既有资料权限。
撤销标记后即时收回浏览器写入/审批；不升级原 user、agent 或 research 档案。

开发基线尚无 #27 的 Web 组件（历史导入向导为 CLI）。本项提供任务入口所需的共享
清单、身份决定和 diff 组件；所有身份、批准、发布及幂等规则仍由现有导入服务执行。
Web 使用 React/TanStack Query/Router、OpenAPI 类型和运行时响应校验；
Go HTTP 按设备、学习区、集合、权限与隐私代次约束命令，PostgreSQL 是状态权威，
正文沿用每任务加密暂存。研究及内容运行由 mentorrun owner 持有。

## 开发方案

1. 增加 mentorrun 的有界列表读取及 HTTP/OpenAPI 合同，按原 kind、status、游标查询，
   不复制运行状态或正文。导入继续使用现有列表、详情及批次接口，不改 CLI DTO。
2. `/app/runs` 使用类型适配器呈现运行和导入，各自分页；学习区及导入集合为明确筛选。
   卡片和详情保留 owner 的阶段、结果未知、错误、预算与发布计数。详情 URL 可刷新恢复。
3. 导入先扫描用户明确选择的 Markdown/UTF-8 文本，显示逐项错误及选择，固定完整清单。
   任务 1000 文件/128 MiB、单文件 4 MiB、单请求 16 MiB 限制不变；逐文件 base64 上传。
   任务创建前固定 UUID，恢复先读取同一任务，再核对全部来源摘要，只上传 pending/missing。
4. 预览完整批次计划，逐批按需加载身份审阅及差异。确认绑定服务端 plan_version，
   逐次继续先 GET 对账；网络错误停止后续请求，不自动换 operation 或重传全部文件。
   切页只停止浏览器观察和后续请求；取消调用原命令并保留已发布结果。
5. 浏览器仅内存保留 File/正文，无恢复正文或凭据落盘；重新进入从原设备服务端列表发现任务。
   学习区归档禁止继续但允许查询/取消，过期、缺暂存、来源变化和基线变化各有明确提示。
   身份及查询缓存复用既有隔离，不允许旧区迟到请求推进新任务。
6. 更新能力、部署白名单、使用说明及验收记录。分两个垂直阶段（导入、统一列表）实施，
   同属一个可恢复任务工作流，不引入新的执行、存储、同步或 PDF 子系统。

## 验收标准

- 真实浏览器一次选择超过 16 MiB 的合法文件；单任务分段上传、预览不发布、确认后逐批发布。
- 刷新、重启及响应丢失恢复原任务和 operation；不重复文档/revision。
- 未上传文件明确要求重新选择；全部原清单核对失败时不上传、不使用旧批准继续。
- 身份冲突使用服务端候选和原有 resolve；预览展示清单、摘要、批次、差异与影响。
- 真实状态分别呈现上传、解析、批准、发布、未知、失败、过期和取消；取消保留已发布。
- 研究/内容/导入按类型适配器列出、筛选、分页、导航；没有伪同步任务或通用成功率。
- 设备、学习区、隐私代次及归档门禁有效；关闭详情不发送停止命令。
- 长清单分页、手机操作可见；浏览器存储无正文或凭据。
- 定向 Web 单测、类型检查、构建、浏览器；Go 受影响包与 OpenAPI；真实 PG 暂存、
  过期、配额、来源/基线变化、隐私及 CLI 原合同回归。未运行/skip 必须单独记录。

## 交付边界

不自动跨设备接管、不后台扫描、不扩张格式、不降低限制、不改历史迁移。
初次交付保留任务分支供审查；用户验收后另行授权合并 `main`、squash 落地和推送，
落地时保留 #27 的参考资料入口、单批导入与显式 `references` 授权，不替换其业务合同。
