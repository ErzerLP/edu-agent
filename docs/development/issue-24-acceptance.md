- 首页开始操作明确保存/选择目标并授权公开搜索、模型准备、资料采纳和预算；仅保存仍没有模型、运行或教学会话副作用。已有现场从原列表明确选择，新开学明确新建现场。

- 追加迁移 24。知识政策与实际上下文分离；概念使用目标内语义键而非文档标题，修订保存真实支持关系。相同政策推进 context，不改目标标准；旧记录不重写 ID/事件。
- `learningstart` 在同一发布事务中调用原 learning/tutoring 应用服务和各 owner 窄接口，提交 context、概念、正式路线/活动、加密 artifact 及运行结果。所有外部请求在事务外；发布前重新裁决身份、目标、区、运行租约和隐私代次。原 `validatePlanningReferences` 未删除或放宽。
- 会话/活动有可空 context 与 artifact 修订关联，后续活动也同事务生成正文。旧 Activity JSON 和 `open` 类型保持兼容，新增查询独立协商；新上下文不会覆盖旧题目、rubric 或正文版本。
- 研究页显示真实阶段、用量、失败与恢复；成功进入原课堂，侧栏列出概念及支持片段，不写 mastery/Evidence。模式查询参数独立于引用锚点，课堂检索优先使用现场实际版本。
- 同步 OpenAPI、Web DTO、部署代理白名单以及各 owner 的隐私清除/核验。全局清除包含所有新增派生关系，清除单个运行仍保留已正规采纳的知识。
